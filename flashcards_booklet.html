Star (Y) vs Delta (Δ) Voltage & Current Relations

📌 PROBLEM / QUESTION:
In a balanced 3-phase positive-sequence ($abc$) system, state the exact relationships between line quantities ($V_L, I_L$) and phase quantities ($V_p, I_p$) for both Y-connection and $\Delta$-connection.
📐 KEY FORMULAS & DEFINITIONS:
Y: $V_L = \sqrt{3}V_p\angle +30^\circ,\ I_L = I_p$ $\Delta$: $V_L = V_p,\ I_L = \sqrt{3}I_p\angle -30^\circ$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Star (Y) Connection:
- Line Voltage leads Phase Voltage by $30^\circ$: $V_{ab} = \sqrt{3}V_{an}\angle +30^\circ$
- Line Current equals Phase Current: $I_L = I_p$

2. Delta (Δ) Connection:
- Line Voltage equals Phase Voltage: $V_L = V_p$
- Line Current lags Phase Current by $30^\circ$: $I_a = \sqrt{3}I_{ab}\angle -30^\circ$

⚠️ EXAM PITFALL & CAUTION:

In negative sequence (acb), line voltage leads by -30° (or lags by 30°). Remember: in Y, currents are identical; in Δ, voltages are identical.

Delta to Wye (Δ ↔ Y) Impedance Conversion

📌 PROBLEM / QUESTION:
If a balanced $3\phi$ load is connected in $\Delta$ with impedance $Z_\Delta = 60 + j30\ \Omega$, what is the equivalent impedance per phase when converted to a Wye (Y) connection ($Z_Y$)?
📐 KEY FORMULAS & DEFINITIONS:
$Z_Y = \frac{Z_\Delta}{3}\quad \Leftrightarrow\quad Z_\Delta = 3 Z_Y$
📝 STEP-BY-STEP MODEL SOLUTION:

$$Z_Y = \frac{Z_\Delta}{3} = \frac{60 + j30}{3} = 20 + j10\ \Omega$$
Conversely, converting from Wye to Delta: $Z_\Delta = 3 Z_Y$.

⚠️ EXAM PITFALL & CAUTION:

Multiplying by 3 instead of dividing is a classic mistake! Delta load draws 3 times more current than Wye load of the same impedance, so equivalent Wye impedance must be 3 times smaller.

Three-Phase Power Formulas & Complex Power

📌 PROBLEM / QUESTION:
State the formulas for balanced $3\phi$ Real Power ($P_{3\phi}$), Reactive Power ($Q_{3\phi}$), Apparent Power ($|S_{3\phi}|$), and Complex Power ($S_{3\phi}$) in terms of line values ($V_L, I_L$).
📐 KEY FORMULAS & DEFINITIONS:
$P_{3\phi} = \sqrt{3}V_L I_L \cos\theta\quad [\text{W}]$ $Q_{3\phi} = \sqrt{3}V_L I_L \sin\theta\quad [\text{VAR}]$ $|S_{3\phi}| = \sqrt{3}V_L I_L\quad [\text{VA}]$ $S_{3\phi} = \sqrt{3}V_L I_L^* = P + jQ$
📝 STEP-BY-STEP MODEL SOLUTION:

When using Line values ($V_L, I_L$), always include the factor $\sqrt{3}$.
When using Phase values ($V_p, I_p$), use factor $3$:
- $P = 3 V_p I_p \cos\theta$
- $Q = 3 V_p I_p \sin\theta$
- $S = 3 V_p I_p^*$
where $\theta = \angle Z_p$ is the load phase impedance angle, and $PF = \cos\theta$.

⚠️ EXAM PITFALL & CAUTION:

Never mix $\sqrt{3}$ with phase quantities! It is either $\sqrt{3}V_L I_L$ or $3 V_p I_p$.

Balanced 4-Wire Y-Y System Full Calculation

📌 PROBLEM / QUESTION:
In the balanced Y-Y circuit shown below, source phase voltages are $V_{an} = 220\angle 0^\circ\text{ V}$, $V_{bn} = 220\angle -120^\circ\text{ V}$, $V_{cn} = 220\angle -240^\circ\text{ V}$. Line impedance $Z_{\text{line}} = 10 + j5\ \Omega$. Balanced load impedance $Z_L = 20 + j50\ \Omega$. Find: (1) Line voltages $V_{ab}, V_{bc}, V_{ca}$, (2) Line currents $I_{aA}, I_{bB}, I_{cC}$, (3) Neutral current $I_{Nn}$, (4) Total $3\phi$ complex power $S$.
รูปประกอบ: Homework 6 Figure 1: Balanced Y-Y System
📐 KEY FORMULAS & DEFINITIONS:
$V_{ab} = \sqrt{3}V_{an}\angle +30^\circ$ $I_{aA} = \frac{V_{an}}{Z_{\text{line}} + Z_L}$ $I_{Nn} = 0$ $S_{3\phi} = 3 V_{an} I_{aA}^*$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Line Voltages:
- $V_{ab} = \sqrt{3}(220)\angle (0^\circ + 30^\circ) = 381.05\angle 30^\circ\text{ V}$
- $V_{bc} = 381.05\angle -90^\circ\text{ V}$
- $V_{ca} = 381.05\angle -210^\circ\text{ V}$

2. Per-phase total impedance:
$$Z_{\text{total}} = (10 + j5) + (20 + j50) = 30 + j55\ \Omega = 62.65\angle 61.39^\circ\ \Omega$$

3. Line Currents:
- $I_{aA} = \frac{220\angle 0^\circ}{62.65\angle 61.39^\circ} = 3.51\angle -61.39^\circ\text{ A}$
- $I_{bB} = 3.51\angle -181.39^\circ\text{ A}$
- $I_{cC} = 3.51\angle 58.61^\circ\text{ A}$

4. Neutral Current:
In a balanced system, $I_{Nn} = 0\text{ A}$, $V_{Nn} = 0\text{ V}$.

5. Total $3\phi$ Power:
$$S = 3 \times 220 \times 3.51\angle +61.39^\circ = 2,316.6\angle 61.39^\circ\text{ VA} = 1,109\text{ W} + j2,034\text{ VAR}$$

⚠️ EXAM PITFALL & CAUTION:

Always remember to conjugate the current ($I^*$) when calculating complex power: $S = V I^*$. The angle of $S$ equals the angle of $Z$.

Unbalanced 4-Wire Y-Y System with Neutral Wire

📌 PROBLEM / QUESTION:
In the 4-wire Y-Y system shown below, the source is balanced $220\text{ V}$ rms, line impedance $Z_{\text{line}} = 10 + j5\ \Omega$, neutral line impedance $Z_{nN} = 10 + j5\ \Omega$, and the load is UNBALANCED: $Z_A = 20 + j50\ \Omega$, $Z_B = 10 + j50\ \Omega$, $Z_C = 20 + j20\ \Omega$. How do you solve for the Neutral Shift Voltage ($V_{Nn}$) and line currents?
รูปประกอบ: Homework 6 Figure 2: Unbalanced Y-Y 4-Wire with Neutral Line
📐 KEY FORMULAS & DEFINITIONS:
$$V_{Nn} = \frac{\frac{V_{an}}{Z_a'} + \frac{V_{bn}}{Z_b'} + \frac{V_{cn}}{Z_c'}}{\frac{1}{Z_a'} + \frac{1}{Z_b'} + \frac{1}{Z_c'} + \frac{1}{Z_{nN}}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Millman's / Node Voltage at Neutral node N:
Let node n be the reference ($0\text{ V}$).
Total phase branch impedances:
- $Z_a' = (10+j5) + (20+j50) = 30 + j55\ \Omega$
- $Z_b' = (10+j5) + (10+j50) = 20 + j55\ \Omega$
- $Z_c' = (10+j5) + (20+j20) = 30 + j25\ \Omega$
- $Z_{nN} = 10 + j5\ \Omega$

2. Solve for $V_{Nn}$ using KCL at node N:
$$\frac{V_N - V_{an}}{Z_a'} + \frac{V_N - V_{bn}}{Z_b'} + \frac{V_N - V_{cn}}{Z_c'} + \frac{V_N}{Z_{nN}} = 0$$

3. Calculate Line Currents:
- $I_{aA} = \frac{V_{an} - V_{Nn}}{Z_a'}$
- $I_{bB} = \frac{V_{bn} - V_{Nn}}{Z_b'}$
- $I_{cC} = \frac{V_{cn} - V_{Nn}}{Z_c'}$
- $I_{Nn} = \frac{V_{Nn}}{Z_{nN}} = I_{aA} + I_{bB} + I_{cC}$

⚠️ EXAM PITFALL & CAUTION:

Do NOT assume $V_{Nn} = 0$! In an unbalanced system, current flows through the neutral wire, causing a non-zero neutral shift voltage $V_{Nn} \neq 0$.

Unbalanced 3-Wire Y-Y System (NO Neutral Wire)

📌 PROBLEM / QUESTION:
In the 3-wire Y-Y system shown below (NO neutral wire), the load is unbalanced ($Z_A \neq Z_B \neq Z_C$). How is the neutral shift voltage $V_{Nn}$ calculated, and what happens to the neutral impedance term in the Millman formula?
รูปประกอบ: Homework 6 Figure 3: Unbalanced Y-Y 3-Wire System
📐 KEY FORMULAS & DEFINITIONS:
$$V_{Nn} = \frac{\frac{V_{an}}{Z_a'} + \frac{V_{bn}}{Z_b'} + \frac{V_{cn}}{Z_c'}}{\frac{1}{Z_a'} + \frac{1}{Z_b'} + \frac{1}{Z_c'}}$$ $$I_{aA} + I_{bB} + I_{cC} = 0$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Floating Neutral Point:
Because there is no neutral conductor, $Z_{nN} = \infty$, meaning the admittance term $\frac{1}{Z_{nN}} = 0$.

2. Node Voltage equation at N:
$$V_{Nn} = \frac{V_{an} Y_a' + V_{bn} Y_b' + V_{cn} Y_c'}{Y_a' + Y_b' + Y_c'}$$
where $Y_x' = \frac{1}{Z_x'}$.

3. Zero Neutral Current:
Without a neutral path, $I_{Nn} = 0$ strictly holds, which means:
$$I_{aA} + I_{bB} + I_{cC} = 0$$

⚠️ EXAM PITFALL & CAUTION:

Even though $I_{Nn} = 0$ (no physical wire), $V_{Nn}$ is NOT zero! The neutral point floats and shifts severely, subjecting some phases to dangerous overvoltages.

📌 HW Ch.6 Problem 4 (12 HP Y-Motor)

3-Phase Motor Input Power, Efficiency & Line Current

📌 PROBLEM / QUESTION:
A $3\phi, 12\text{-hp}$ induction motor is connected in Y to a balanced $380\text{ V}, 50\text{ Hz}$ supply. The motor has efficiency $\eta = 90\%$ and $PF = 0.85$ lagging. Calculate: (1) Input electrical power $P_{\text{in}}$, (2) Line current $I_L$, (3) Total complex power $S$, (4) Equivalent impedance per phase $Z_Y$.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{out}} = 12 \times 746\text{ W} = 8,952\text{ W}$$ $$P_{\text{in}} = \frac{P_{\text{out}}}{\eta}$$ $$I_L = \frac{P_{\text{in}}}{\sqrt{3} V_L \cdot PF}$$ $$S = \frac{P_{\text{in}}}{PF}\angle \arccos(PF)$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Convert output power to Watts:
$$P_{\text{out}} = 12 \times 746 = 8,952\text{ W}$$

2. Input Electrical Real Power:
$$P_{\text{in}} = \frac{8,952}{0.90} = 9,946.67\text{ W} \approx 9.95\text{ kW}$$

3. Line Current ($I_L$):
$$I_L = \frac{9,946.67}{\sqrt{3} \times 380 \times 0.85} = \frac{9,946.67}{559.45} = 17.78\text{ A}$$

4. Complex Power ($S$):
$$\theta = \arccos(0.85) = 31.79^\circ$$
$$|S| = \frac{9.946}{0.85} = 11.70\text{ kVA}$$
$$S = 11.70\angle 31.79^\circ\text{ kVA} = 9.95\text{ kW} + j6.16\text{ kVAR}$$

5. Per-Phase Impedance ($Z_Y$):
$$V_p = \frac{380}{\sqrt{3}} = 219.39\text{ V}$$
$$Z_Y = \frac{V_p}{I_L} = \frac{219.39}{17.78}\angle 31.79^\circ = 12.34\angle 31.79^\circ\ \Omega = 10.49 + j6.50\ \Omega$$
($R = 10.49\ \Omega$, $L = \frac{6.50}{2\pi \times 50} = 20.7\text{ mH}$)

⚠️ EXAM PITFALL & CAUTION:

Remember: $1\text{ hp} = 746\text{ W}$. Horsepower is ALWAYS mechanical output power at the shaft ($P_{\text{out}}$), never electrical input power ($P_{\text{in}}$)!

Delta-Connected 3-Phase Motor Analysis

📌 PROBLEM / QUESTION:
A $3\phi, 10\text{-hp}$ induction motor is connected in $\Delta$ to a $380\text{ V}, 50\text{ Hz}$ supply. $\eta = 85\%, PF = 0.80$ lagging. Find: (1) Input power $P_{\text{in}}$, (2) Line current $I_L$, (3) Phase winding current $I_\Delta$, (4) Phase impedance $Z_\Delta$.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{in}} = \frac{10 \times 746}{0.85}$$ $$I_L = \frac{P_{\text{in}}}{\sqrt{3} V_L PF}$$ $$I_\Delta = \frac{I_L}{\sqrt{3}}$$ $$Z_\Delta = \frac{V_L}{I_\Delta}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Input Power:
$$P_{\text{in}} = \frac{7,460\text{ W}}{0.85} = 8,776.47\text{ W} = 8.78\text{ kW}$$

2. Line Current:
$$I_L = \frac{8,776.47}{\sqrt{3} \times 380 \times 0.80} = 16.67\text{ A}$$

3. Delta Phase Current:
In $\Delta$, line current divides: $I_\Delta = \frac{I_L}{\sqrt{3}} = \frac{16.67}{1.732} = 9.62\text{ A}$

4. Impedance per phase ($Z_\Delta$):
In $\Delta$, $V_p = V_L = 380\text{ V}$.
$$|Z_\Delta| = \frac{V_p}{I_\Delta} = \frac{380}{9.62} = 39.50\ \Omega$$
$$\theta = \arccos(0.8) = 36.87^\circ$$
$$Z_\Delta = 39.50\angle 36.87^\circ\ \Omega = 31.60 + j23.70\ \Omega$$

⚠️ EXAM PITFALL & CAUTION:

In a Delta load, $V_p = V_L = 380\text{ V}$, but $I_p = I_L / \sqrt{3}$. Do not divide voltage by $\sqrt{3}$ for a Delta load!

Two-Wattmeter Method for 3-Phase Power Measurement

📌 PROBLEM / QUESTION:
In the two-wattmeter method measuring a balanced 3-phase load, state the equations for total real power ($P_{\text{total}}$), total reactive power ($Q_{\text{total}}$), and the load power factor angle ($\theta$) in terms of wattmeter readings $W_1$ and $W_2$.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{total}} = W_1 + W_2$$ $$Q_{\text{total}} = \sqrt{3}(W_1 - W_2)$$ $$\tan\theta = \sqrt{3}\frac{W_1 - W_2}{W_1 + W_2}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Total Active Power is simply the algebraic sum:
$$P = W_1 + W_2$$

2. Total Reactive Power is proportional to the difference:
$$Q = \sqrt{3}(W_1 - W_2)$$

3. Phase angle of the load:
$$\theta = \arctan\left(\sqrt{3}\frac{W_1 - W_2}{W_1 + W_2}\right)$$
$$PF = \cos\theta$$

Special Cases:
- If $PF = 1.0$: $W_1 = W_2$
- If $PF = 0.5$: One wattmeter reads zero ($W_2 = 0$)
- If $PF < 0.5$: One wattmeter reads NEGATIVE!

⚠️ EXAM PITFALL & CAUTION:

When $PF < 0.5$, one wattmeter reads negative! On an analog meter, reverse the current coil connections to read the value, then treat that reading as a negative number in $W_1 + W_2$.

Power Factor Correction with Delta Capacitors

📌 PROBLEM / QUESTION:
A balanced $3\phi$ inductive load of $30\text{ kW}$ operates at $380\text{ V}, 50\text{ Hz}$ with $PF_1 = 0.65$ lagging. What total reactive power $Q_C$ must a capacitor bank supply to improve the power factor to $PF_2 = 0.95$ lagging, and what is the capacitance per phase if connected in Delta ($C_\Delta$)?
📐 KEY FORMULAS & DEFINITIONS:
$$Q_C = P(\tan\theta_1 - \tan\theta_2)$$ $$C_\Delta = \frac{Q_{C,\text{phase}}}{\omega V_L^2} = \frac{Q_C / 3}{2\pi f V_L^2}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Find power factor angles:
- $\theta_1 = \arccos(0.65) = 49.46^\circ \Rightarrow \tan\theta_1 = 1.169$
- $\theta_2 = \arccos(0.95) = 18.19^\circ \Rightarrow \tan\theta_2 = 0.329$

2. Required 3-phase Reactive Power from Capacitors:
$$Q_C = 30\text{ kW} \times (1.169 - 0.329) = 30 \times 0.840 = 25.20\text{ kVAR}$$

3. Delta connection per-phase capacitance:
Each branch sees full line voltage $V_L = 380\text{ V}$ and supplies $Q_{C1} = \frac{25,200}{3} = 8,400\text{ VAR}$:
$$C_\Delta = \frac{8,400}{2\pi(50)(380)^2} = \frac{8,400}{314.16 \times 144,400} = 1.85 \times 10^{-4}\text{ F} = 185\ \mu\text{F}$$

⚠️ EXAM PITFALL & CAUTION:

Capacitors connected in Delta require 3 times LESS capacitance than Wye-connected capacitors ($C_\Delta = C_Y / 3$) for the same reactive power, saving massive physical space and cost!

3-Phase Induction Motor & Squirrel-Cage Rotor Operation

📌 PROBLEM / QUESTION:
Referring to the 3-phase induction motor diagram below: (1) What is a Squirrel-Cage Rotor and how does it work? (2) Explain the operating principle of a 3-phase induction motor. (3) How do you reverse its direction of rotation?
รูปประกอบ: Homework 7 Problem 4: DC Shunt Motor Equivalent Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$n_s = \frac{120 f}{P}$$ $$s = \frac{n_s - n_r}{n_s}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Squirrel-Cage Rotor (โรเตอร์แบบกรงกระรอก):
Consists of conducting aluminum/copper bars embedded in laminated iron core, short-circuited at both ends by end-rings. When the rotating magnetic field sweeps across the bars, it induces currents producing torque.

2. Operating Principle:
3-phase stator currents produce a Constant-Magnitude Rotating Magnetic Field (RMF) spinning at synchronous speed $n_s = 120f/P$. By Faraday-Lenz law, this field cuts rotor bars, inducing voltage and rotor currents. The interaction generates Lorentz torque, pulling the rotor in the direction of the rotating field.

3. Direction Reversal:
Swap ANY TWO supply phase lines (e.g., swap A and B, keeping C fixed). This reverses the phase sequence and rotates the RMF in the opposite direction.

⚠️ EXAM PITFALL & CAUTION:

The rotor can NEVER reach synchronous speed ($n_r < n_s$). If $n_r = n_s$, relative velocity is zero, no voltage is induced, and torque drops to zero!

DC Generator Principle & Commutator Rectification

📌 PROBLEM / QUESTION:
What machine is shown in the diagram below and how does it work? Explain how the split-ring commutator converts induced AC into pulsating DC at the output terminals.
รูปประกอบ: Homework 7 Problem 5: DC Series Motor Equivalent Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$e = B\ell v \sin\theta$$ $$E_a = k_a \phi \omega_m$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Identification:
Single-phase DC Generator with split-ring commutator.

2. Principle of Operation:
Mechanical power drives the coil rotating in the magnetic field between permanent magnet poles. By Faraday's Law, an alternating electromotive force ($e = B\ell v$) is induced inside the rotating coil.

3. Commutator Action:
The split-ring commutator mechanically reverses coil connections to the external stationary carbon brushes every half revolution, rectifying the internal alternating AC into unidirectional pulsating DC.

⚠️ EXAM PITFALL & CAUTION:

Inside ANY rotating DC armature, the induced voltage is ALWAYS AC! The commutator is what converts internal AC into external DC.

DC Shunt Motor Equivalent Circuit, Speed & Torque

📌 PROBLEM / QUESTION:
A 2-pole, $2.5\text{-hp}, 100\text{ VDC}$ shunt motor has design constant $k_a = 153$. At full load, $I_t = 25.0\text{ A}, R_a = 0.75\ \Omega, \phi = 10.0\text{ mWb}, R_f = 440\ \Omega$. $$I_f = \frac{V_t}{R_f},\quad I_a = I_t - I_f$$ $$E_a = V_t - I_a R_a = k_a \phi \omega_m$$ $$\omega_m = \frac{2\pi n}{60},\quad \tau_d = k_a \phi I_a$$

Induction Motor Power Flow: Air-Gap, Copper Loss & Mech Power

📌 PROBLEM / QUESTION:

Synchronous Motor Operation, V-Curve & Power Factor Correction

📌 PROBLEM / QUESTION:
Why does a Synchronous Motor rotate at exactly synchronous speed with zero slip ($s=0$)? How does varying its DC field excitation current ($I_f$) allow it to act as a Synchronous Condenser to correct facility power factor?
📐 KEY FORMULAS & DEFINITIONS:
$$n_r = n_s = \frac{120f}{P}$$ Normal excitation: $PF = 1.0$ Over-excitation: Leading $PF$ (supplies Q) Under-excitation: Lagging $PF$ (draws Q)
📝 STEP-BY-STEP MODEL SOLUTION:

1. Constant Synchronous Speed:
The rotor's DC-excited poles lock magnetically into synchronism with the stator's rotating magnetic field. As long as load does not exceed pull-out torque, it runs at precisely $n_s$.

2. V-Curve & Power Factor Control:
- Under-excited ($I_f$ small): Motor draws lagging reactive power ($Q > 0$).
- Normal excitation: Motor operates at unity power factor ($PF = 1.0$), minimum stator current.
- Over-excited ($I_f$ large): Motor draws leading reactive power (acts as a capacitor, supplying VARs to the grid to correct factory power factor).

⚠️ EXAM PITFALL & CAUTION:

Synchronous motors are NOT inherently self-starting from a dead stop because the stator RMF moves past stationary rotor poles too fast for inertia to catch up. They require damper (amortisseur) windings to start as an induction motor first.

DC Motor Starting Current & Starting Resistor Design

📌 PROBLEM / QUESTION:
Why is the starting current of a DC motor dangerously high (10 to 20 times rated current) if started directly on full voltage? How does an external starting resistor protect the motor?
📐 KEY FORMULAS & DEFINITIONS:
At start ($n=0$): $E_a = 0$ $$I_{\text{start}} = \frac{V_t}{R_a}$$ With starter: $$I_{\text{start}} = \frac{V_t}{R_a + R_{\text{start}}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Why Starting Current is Enormous:
At standstill ($n = 0$), back EMF $E_a = k_a \phi \omega_m = 0\text{ V}$. Because armature resistance $R_a$ is designed to be tiny ($< 0.5\ \Omega$) for high efficiency:
$$I_{\text{start}} = \frac{V_t - 0}{R_a} = \frac{220\text{ V}}{0.5\ \Omega} = 440\text{ A}!$$
This burns the armature coils and melts commutator brushes.

2. Protection via Starting Resistor:
A multi-step starting resistance $R_{\text{start}}$ is placed in series with the armature to limit starting current to $1.5 - 2.0 \times I_{\text{rated}}$. As the motor accelerates and builds up $E_a$, resistance steps are cut out.

⚠️ EXAM PITFALL & CAUTION:

Never start a DC motor under full voltage without starting resistance (except tiny sub-fractional HP motors).

Danger of Open Field Circuit in DC Shunt Motor

📌 PROBLEM / QUESTION:
What happens if the shunt field circuit of a running DC shunt motor accidentally breaks or becomes open-circuited ($I_f = 0$)? Explain the physical mechanism.
📐 KEY FORMULAS & DEFINITIONS:
$$n = \frac{V_t - I_a R_a}{k_a \phi}$$ As $\phi \to \phi_{\text{residual}} \approx 0 \Rightarrow n \to \infty$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Field current drops to zero ($I_f = 0$), so magnetic flux drops to residual magnetism ($\phi \to \phi_{\text{residual}} \approx 0$).
2. Back EMF collapses: $E_a \approx 0$, causing armature current $I_a = \frac{V_t - E_a}{R_a}$ to soar to destructive levels.
3. Because $n \propto \frac{1}{\phi}$, the motor accelerates uncontrollably to catastrophic runaway speed ($n \to \infty$), resulting in mechanical disintegration (throwing armature windings and bearings exploding).

Never install a fuse or switch in the field winding of a DC shunt motor! An open field causes motor destruction.

DC Series Motor Prohibition Against No-Load Operation

📌 PROBLEM / QUESTION:
Why is it strictly forbidden to run a DC Series Motor without a mechanical load (or with a belt drive that could snap)?
📐 KEY FORMULAS & DEFINITIONS:
Series motor: $\phi \propto I_a$ $$n \propto \frac{V_t - I_a(R_a + R_f)}{k_a \phi} \approx \frac{V_t}{k' I_a}$$ As $I_a \to 0 \Rightarrow n \to \infty$
📝 STEP-BY-STEP MODEL SOLUTION:

1. In a series motor, field current equals armature current ($I_f = I_a$).
2. At no load, torque required is near zero, so armature current drops close to zero ($I_a \to 0$).
3. This causes magnetic flux to drop to residual levels ($\phi \to 0$).
4. Speed $n \propto \frac{1}{\phi} \propto \frac{1}{I_a}$ races towards dangerous infinity ($n \to \infty$), destroying the machine by centrifugal force.

⚠️ EXAM PITFALL & CAUTION:

Series motors MUST ALWAYS be solidly coupled (gears/direct shaft) to their load, NEVER belt-driven!

Transformer Losses: Core Loss vs Copper Loss

📌 PROBLEM / QUESTION:
What types of power losses occur in a real transformer? Contrast Core Loss (Iron Loss) with Copper Loss (Winding Loss) regarding their cause and load dependency.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{total loss}} = P_{\text{core}} + P_{\text{cu}}$$ $$P_{\text{core}} = P_h + P_e\quad (\text{constant 24/7})$$ $$P_{\text{cu}} = I_1^2 R_1 + I_2^2 R_2 \propto I_L^2$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Core Loss (Iron Loss / การสูญเสียในแกนเหล็ก):
- Hysteresis loss ($P_h \propto f B_{\max}^{1.6}$) + Eddy current loss ($P_e \propto f^2 B_{\max}^2 t^2$).
- Constant 24/7: Depends only on applied voltage and frequency; independent of load current!

2. Copper Loss ($I^2 R$ Loss / การสูญเสียในขดลวดทองแดง):
- Caused by Joule heating in primary and secondary winding resistances.
- Variable: Proportional to the square of load current ($P_{\text{cu}} \propto I_L^2$). Zero at no load!

⚠️ EXAM PITFALL & CAUTION:

Transformer Voltage Regulation Formula & Power Factor Dependency

📌 PROBLEM / QUESTION:
State the formula for Transformer Voltage Regulation ($VR\%$). How does the power factor (lagging vs leading) affect voltage regulation, and can $VR\%$ ever be negative?

$$VR\% = \frac{V_{NL} - V_{FL}}{V_{FL}} \times 100\%$$ Approx: $$VR\% \approx \frac{I_2 R_{eq2} \cos\theta \pm I_2 X_{eq2} \sin\theta}{V_2} \times 100\%$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Formula:
$$VR\% = \frac{V_{2,NL} - V_{2,FL}}{V_{2,FL}} \times 100\%$$

Auto-Transformer Principle, Higher kVA Rating & Common Winding Risk

📌 PROBLEM / QUESTION:
What is an Auto-Transformer? Why does it possess a higher kVA power rating and higher efficiency than a conventional two-winding transformer of the same physical size, and what is its primary safety drawback?
📐 KEY FORMULAS & DEFINITIONS:
$$\frac{S_{\text{auto}}}{S_{\text{2-w}}} = \frac{1}{1 - 1/a_{\text{auto}}}$$ Conducted power + Transformed power
📝 STEP-BY-STEP MODEL SOLUTION:

1. Construction & Principle:
An auto-transformer has a SINGLE continuous winding shared partly by both primary and secondary circuits (tapped common winding).

2. Higher Rating & Efficiency:
Power is transferred via two mechanisms simultaneously:
- By electromagnetic induction (transformed power)
- By direct electrical conduction (conducted power)

3. Safety Drawback:
NO ELECTRICAL ISOLATION between primary (HV) and secondary (LV)! If the common ground connection opens, the full high voltage appears directly on the low voltage terminals, risking electrocution.

⚠️ EXAM PITFALL & CAUTION:

Never use an autotransformer where human safety isolation from high voltage mains is required (e.g. medical equipment or bathroom supplies).

Transmission Tower Classifications & Structures

📌 PROBLEM / QUESTION:
Classify transmission tower structures into Suspension, Tension, Dead-end, and Transposition towers, stating the mechanical and electrical purpose of each.

📐 KEY FORMULAS & DEFINITIONS:
$$\text{Suspension: Straight paths, supports vertical conductor weight}$$
$$\text{Tension / Angle: Turns/corners, withstands directional pull tension}$$
$$\text{Dead-end: Terminal stations, handles one-sided full mechanical tension}$$
$$\text{Transposition: Balances mutual inductance } L_{12} = L_{23} = L_{31} \text{ and capacitance across 3 phases}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Suspension Towers (เสาแขวน):
Used along straight line routes. Insulators hang vertically downwards to support only the physical downward weight of conductors without taking longitudinal line tension.

2. Tension / Angle Towers (เสารั้ง / เสามุม):
Installed where transmission line changes direction (curves/corners). Insulators are placed horizontally in tension to withstand the horizontal mechanical pulling vector.

3. Dead-end / Terminal Towers (เสาสิ้นสุด):
Placed where the line terminates at a substation or crosses major obstacles (wide rivers, mountains). Engineered to withstand the full, unbalanced tension from one side.

4. Transposition Towers (เสาสลับเฟส):
Swaps physical conductor positions at regular 1/3 distance intervals to equalize line inductances and capacitances, balancing phase voltages.

⚠️ EXAM PITFALL & CAUTION:

Transposition is done solely for electrical symmetry (equalizing mutual inductance and capacitance), preventing unbalance on long 3-phase lines.

PMMC / Galvanometer Working Principle & Deflection Torque

📌 PROBLEM / QUESTION:
Explain the operating principle of a Permanent Magnet Moving Coil (PMMC / D'Arsonval) instrument. State the formula for deflecting torque and explain why PMMC instruments only measure DC directly.
📐 KEY FORMULAS & DEFINITIONS:
$$T_d = B \cdot I \cdot N \cdot A = G \cdot I$$
$$T_c = C \cdot \theta$$
$$\text{At equilibrium: } T_d = T_c \implies \theta = \left(\frac{G}{C}\right) I \propto I$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Operating Principle:
A rectangular copper coil carrying current I is pivoted inside the magnetic field B of a permanent magnet. The interaction of current and magnetic flux creates a Lorentz force (F = I*L x B), producing a deflecting torque Td.

2. Linear Scale:
Since deflecting torque Td = B*I*N*A and restoring spring torque Tc = C*theta, at steady state:
theta = (B*N*A / C) * I
Because B, N, A, and C are constant, the pointer deflection angle theta is directly proportional to current I, yielding a perfectly LINEAR scale.

3. Why DC Only:
If connected to alternating current (AC), the torque alternates direction every half-cycle (50 Hz). Due to the mechanical inertia of the moving coil and pointer, the meter cannot follow this rapid oscillation and indicates strictly the AVERAGE value, which is ZERO for pure sinusoidal AC.

⚠️ EXAM PITFALL & CAUTION:

รูปประกอบ: Homework 10 Problem 2: DC Ammeter Design with and without CDRX
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Without CDRX: } R_{\text{sh}} = \frac{I_{\text{fsd}} R_m}{I - I_{\text{fsd}}} = \frac{R_m}{m - 1}$$
$$\text{With CDRX: Series resistor } R_s = \text{CDRX} - R_m$$
$$R_{\text{sh}}' = \frac{I_{\text{fsd}} (R_m + R_s)}{I - I_{\text{fsd}}} = \frac{I_{\text{fsd}} \cdot \text{CDRX}}{I - I_{\text{fsd}}}$$

📝 STEP-BY-STEP MODEL SOLUTION:

1. Part (a) Without CDRX:
- Shunt resistor Rsh is connected in parallel with Rm:

Ayrton Shunt (Universal Shunt) for Multi-Range Ammeter

📌 PROBLEM / QUESTION:
What is an Ayrton Shunt (Universal Shunt)? Why is it superior to individual switched shunts, and how do you calculate the resistor values Ra, Rb, and Rc for multi-range operation?
รูปประกอบ: Ayrton / Universal Shunt Multi-Range Ammeter Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Total Shunt: } R_{\text{sh}} = R_a + R_b + R_c$$
$$\text{Range 1 (Lowest } I_1\text{): } R_{\text{sh}} = \frac{I_{\text{fsd}} R_m}{I_1 - I_{\text{fsd}}}$$

Series-Type Ohmmeter Working Principle & Scale

📌 PROBLEM / QUESTION:
Explain the circuit design of a Series-Type Ohmmeter. Describe its pointer deflection at Rx = 0, Rx = R_half, and Rx = infinity, and explain why its resistance scale is non-linear and reads backwards.
รูปประกอบ: Series-Type Ohmmeter Circuit & Scale
📐 KEY FORMULAS & DEFINITIONS:
$$I = \frac{E}{R_{\text{in}} + R_x}$$
$$R_x = 0 \implies I = I_{\text{fsd}} \quad (\text{Rightmost edge})$$
$$R_x = R_{\text{in}} \implies I = 0.5\, I_{\text{fsd}} \quad (\text{Center of scale: } R_h)$$
$$R_x = \infty \implies I = 0 \quad (\text{Leftmost zero current})$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Circuit Topology:
A battery E, current-limiting resistor R1, zero-adjust rheostat R2, and meter movement Rm are connected in series with the unknown resistor Rx.

2. Calibration Points:
- Rx = 0 (Short Circuit): Full current flows, pointer deflects to FULL SCALE (far RIGHT) = 0 ohms.
- Rx = R_half (R_in): Total resistance doubles, current drops to 50% Ifsd, pointer sits exactly at MID-SCALE = Rh.
- Rx = infinity (Open Circuit): Current is 0, pointer remains at REST (far LEFT) = infinity ohms.

3. Non-linear & Backwards Scale:
Because current I = E / (R_in + Rx) is an inverse hyperbolic function of Rx, deflection is NOT linear. Scale markings are widely spaced on the right (low ohms) and heavily compressed on the left (high ohms).

⚠️ EXAM PITFALL & CAUTION:

Series ohmmeter scale reads 0 on the RIGHT and infinity on the LEFT (opposite to voltmeters and ammeters).

$$I_m = I_{\text{total}} \cdot \frac{R_x}{R_m + R_x}$$

Energy Meter (Kilowatt-Hour Meter) Function

📌 PROBLEM / QUESTION:
Explain the working principle of an induction-type Kilowatt-Hour Meter (kWh meter). What creates the driving torque on the aluminum disc, and what is the role of the permanent brake magnet?
📐 KEY FORMULAS & DEFINITIONS:
$$T_d \propto V \cdot I \cdot \cos\theta = P$$
$$T_b \propto \omega \quad (\text{Eddy-current braking})$$
$$\text{At steady speed: } T_d = T_b \implies \omega \propto P$$
$$\text{Total Revolutions } N = \int \omega\, dt \propto \int P\, dt = \text{Energy (kWh)}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Driving Torque Generation:
The meter contains a shunt electromagnet (connected across line voltage) and a series electromagnet (carrying load current). A C-shaped permanent magnet sits near the edge of the disc. As the disc spins through its field, eddy currents are induced that create a retarding torque Tb proportional to rotational speed (Tb proportional to omega).

3. Energy Integration:

Intrinsic vs Extrinsic, N-Type vs P-Type Semiconductors

📌 PROBLEM / QUESTION:
Distinguish between Intrinsic and Extrinsic semiconductors. Explain how N-Type and P-Type semiconductors are formed by doping, identifying the majority and minority charge carriers in each.
รูปประกอบ: Exam Problem 4.1: Intrinsic & Extrinsic Semiconductors
📐 KEY FORMULAS & DEFINITIONS:
$$\text{N-Type: Si (4 val) + Pentavalent (5 val: P, As, Sb) } \implies \text{Majority: Free Electrons } (e^-)$$
$$\text{P-Type: Si (4 val) + Trivalent (3 val: B, Ga, In) } \implies \text{Majority: Holes } (h^+)$$
$$\text{Mass Action Law: } n \cdot p = n_i^2$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Intrinsic vs Extrinsic Semiconductors:
- Intrinsic: Extremely pure semiconductor crystal (Silicon or Germanium, valence = 4) with no impurities. Electrical conductivity at room temperature is very low.

- Doped with Pentavalent impurity (valence 5: Phosphorus, Arsenic, Antimony).

- Doped with Trivalent impurity (valence 3: Boron, Gallium, Indium).
- 3 valence electrons bond with Silicon, leaving a vacancy or 'hole' that eagerly accepts an electron.
- Majority Carriers: Holes (h+); Minority Carriers: Electrons (e-).

📐 KEY FORMULAS & DEFINITIONS:
$$\text{MOSFET = Metal-Oxide-Semiconductor Field-Effect Transistor}$$
$$\text{Terminals: Gate (G), Drain (D), Source (S)}$$
$$I_G \approx 0 \implies R_{\text{in, gate}} \approx 10^{12} - 10^{14}\,\Omega$$
$$I_D = K (V_{GS} - V_{th})^2 \quad (\text{Voltage-Controlled Device})$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Definition & Terminals:
MOSFET stands for Metal-Oxide-Semiconductor Field-Effect Transistor. Its 3 functional terminals are Gate (G), Drain (D), and Source (S) (with a substrate/body terminal internally tied to Source).

2. Near-Infinite Gate Input Impedance:
The Gate electrode is physically isolated from the semiconductor conducting channel by an ultra-thin dielectric layer of Silicon Dioxide (SiO2). 3. Advantages over BJT:
- Voltage-controlled (requires zero static gate current to remain ON, unlike BJT which demands continuous base current IB).
- Extremely fast switching speeds (ideal for high-frequency switch-mode power supplies and CPU logic gates).
- Low conduction resistance RDS(on) in modern power MOSFETs, yielding high efficiency.

⚠️ EXAM PITFALL & CAUTION:

MOSFET is voltage-controlled (Vgs controls Id). BJT is current-controlled (Ib controls Ic).

PN Junction Diode Biasing & Knee Voltages

📌 PROBLEM / QUESTION:
Explain Forward and Reverse Biasing of a PN junction diode. State the barrier potential (Knee Voltage) for Silicon and Germanium diodes, and explain the mechanism of reverse breakdown.
รูปประกอบ: PN Junction Diode Characteristic Curve & Biasing
📐 KEY FORMULAS & DEFINITIONS:
$$V_{\text{knee, Si}} \approx 0.7\text{ V} \qquad V_{\text{knee, Ge}} \approx 0.3\text{ V}$$
$$\text{Forward: } V_{\text{anode}} > V_{\text{cathode}} + V_{\text{knee}} \implies \text{Conducts heavy current } I_D$$
$$\text{Reverse: } V_{\text{cathode}} > V_{\text{anode}} \implies I_D \approx I_s \text{ (Reverse Saturation Current } \approx \text{nA)}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Forward Bias:
Positive terminal of source connected to Anode (P-type), Negative to Cathode (N-type). When applied voltage exceeds the barrier potential (0.7 V for Si, 0.3 V for Ge), the depletion layer collapses and large forward current flows exponentially.

2. Reverse Bias:
Positive terminal to Cathode (N-type), Negative to Anode (P-type). The external voltage widens the depletion layer, preventing majority carrier flow. Only a tiny temperature-dependent reverse saturation current Is (picoamps to nanoamps) flows.

3. Reverse Breakdown:
If reverse voltage exceeds the Peak Inverse Voltage (PIV / Breakdown Voltage Vz), avalanche multiplication or zener tunneling occurs, causing sudden massive reverse current. Unless current is externally limited by a resistor, the diode will burn out.

⚠️ EXAM PITFALL & CAUTION:

Memorize: Silicon diode Knee Voltage = 0.7 V; Germanium diode Knee Voltage = 0.3 V. Standard problems assume Silicon 0.7 V.

Diode Shockley Equation, Dynamic Resistance & LED Circuit

📌 PROBLEM / QUESTION:
State Shockley's ideal diode equation. Define dynamic AC resistance rd, and calculate the current-limiting resistor R required to operate an LED (V_led = 2.0 V, I_led = 15 mA) from a 12 V DC source.
📐 KEY FORMULAS & DEFINITIONS:
$$I_D = I_s \left( e^{\frac{V_D}{n V_T}} - 1 \right) \qquad V_T = \frac{k T}{q} \approx 26\text{ mV at } 300\text{ K}$$
$$r_d = \frac{n V_T}{I_D} \approx \frac{26\text{ mV}}{I_D}$$
$$R = \frac{V_{CC} - V_{\text{LED}}}{I_{\text{LED}}} = \frac{12\text{ V} - 2.0\text{ V}}{15 \times 10^{-3}\text{ A}} = 667\;\Omega$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Shockley Diode Equation:
ID = Is * [exp(VD / (n*VT)) - 1]
where Is = reverse saturation current, n = ideality factor (1 to 2), VT = thermal voltage = kT/q = 26 mV at room temperature (27°C / 300 K).

2. Dynamic AC Resistance (rd):
Taking the derivative dVD/dID yields:
rd = 26 mV / ID (where ID is in milliamperes).
At ID = 2 mA, rd = 26 mV / 2 mA = 13 ohms.

3. LED Resistor Calculation:
R = (Vcc - V_led) / I_led = (12 V - 2.0 V) / 0.015 A = 10 V / 0.015 A = 666.67 ohms.
Select standard resistor R = 680 ohms.

⚠️ EXAM PITFALL & CAUTION:

Never connect an LED directly to a voltage source without a current-limiting resistor, as diode current rises exponentially and destroys the LED.

Zener Diode Voltage Regulator Operation

📌 PROBLEM / QUESTION:
How does a Zener diode function as a voltage regulator? In a circuit with Vin = 15 V to 20 V, Vz = 10 V, Pz_max = 1 W, and load RL = 500 ohms, calculate the required series resistor R.
รูปประกอบ: Zener Diode Voltage Regulator Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$I_L = \frac{V_Z}{R_L} = \frac{10\text{ V}}{500\;\Omega} = 20\text{ mA}$$
$$I_{Z,\max} = \frac{P_{Z,\max}}{V_Z} = \frac{1\text{ W}}{10\text{ V}} = 100\text{ mA}$$
$$R_{\min} = \frac{V_{\text{in},\max} - V_Z}{I_{Z,\max} + I_L} = \frac{20 - 10}{0.100 + 0.020} = \frac{10}{0.120} = 83.3\;\Omega$$
$$R_{\max} = \frac{V_{\text{in},\min} - V_Z}{I_{Z,\min} + I_L} = \frac{15 - 10}{0.005 + 0.020} = \frac{5}{0.025} = 200\;\Omega$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Zener Regulation Mechanism:
A Zener diode operates in the REVERSE breakdown region. When reverse-biased beyond its breakdown voltage Vz, terminal voltage remains remarkably constant at Vz over a broad range of Zener current Iz.

2. Load Current:
IL = Vz / RL = 10 V / 500 ohms = 20 mA (constant as long as Vz is regulated).

3. Maximum Zener Current:
Iz_max = Pz_max / Vz = 1 W / 10 V = 100 mA.

4. Calculate Minimum Series Resistance R_min (at Vin_max = 20 V):
R_min = (Vin_max - Vz) / (Iz_max + IL) = (20 - 10) / (0.100 + 0.020) = 10 / 0.120 = 83.3 ohms.

5. Calculate Maximum Series Resistance R_max (at Vin_min = 15 V, assuming Iz_min = 5 mA):
R_max = (Vin_min - Vz) / (Iz_min + IL) = (15 - 10) / (0.005 + 0.020) = 5 / 0.025 = 200 ohms.
Any value between 84 ohms and 200 ohms (e.g. standard 120 ohms) guarantees stable 10 V regulation.

⚠️ EXAM PITFALL & CAUTION:

Zener diode must be connected in REVERSE BIAS (Cathode to positive supply) to regulate voltage. In forward bias, it behaves like an ordinary 0.7 V diode!

Solar Photovoltaic Cell Equivalent Circuit & Parameters

📌 PROBLEM / QUESTION:
Draw and explain the electrical equivalent circuit of a Solar Photovoltaic Cell. Define Open-Circuit Voltage (Voc), Short-Circuit Current (Isc), Maximum Power Point (MPP), and Fill Factor (FF).
📐 KEY FORMULAS & DEFINITIONS:
$$I = I_{\text{ph}} - I_D - I_{\text{sh}} = I_{\text{ph}} - I_s \left( e^{\frac{V + I R_s}{n V_T}} - 1 \right) - \frac{V + I R_s}{R_{\text{sh}}}$$
$$P_{\max} = V_{\text{mp}} \cdot I_{\text{mp}}$$
$$\text{Fill Factor: } FF = \frac{P_{\max}}{V_{oc} \cdot I_{sc}} = \frac{V_{\text{mp}} \cdot I_{\text{mp}}}{V_{oc} \cdot I_{sc}}$$
$$\text{Efficiency: } \eta = \frac{P_{\max}}{P_{\text{in}}} = \frac{V_{oc} \cdot I_{sc} \cdot FF}{G \cdot A_{\text{cell}}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Solar Cell Equivalent Circuit:
Consists of a photocurrent source Iph (proportional to solar irradiance) in parallel with:
- An intrinsic PN junction diode (Shockley equation)
- A shunt resistance Rsh (representing leakage current across cell edges, ideally infinity)
- A series resistance Rs (representing bulk silicon and metal contact resistance, ideally zero).

BJT Transistor Terminal Currents & Gain Relations

📌 PROBLEM / QUESTION:
State the current relationship between the Emitter (IE), Base (IB), and Collector (IC) of a Bipolar Junction Transistor (BJT). Define DC current gain Beta (hFE) and Alpha, and derive the formula linking Beta and Alpha.
รูปประกอบ: BJT Transistor Terminal Currents & Alpha-Beta Relations
📐 KEY FORMULAS & DEFINITIONS:
$$I_E = I_B + I_C$$
$$\beta = \frac{I_C}{I_B} \qquad \alpha = \frac{I_C}{I_E}$$
$$\alpha = \frac{\beta}{\beta + 1} \qquad \beta = \frac{\alpha}{1 - \alpha}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Kirchhoff's Current Law for BJT:
By KCL, the total current leaving/entering the emitter equals the sum of base and collector currents:
IE = IB + IC

2. Current Gains Defined:
- Common-Emitter DC Current Gain (Beta or hFE):
Beta = IC / IB (typically ranges from 50 to 300).
- Common-Base DC Current Gain (Alpha):
Alpha = IC / IE (slightly less than 1, typically 0.98 to 0.998).

3. Relationship Derivation:
Divide IE = IB + IC by IC:
IE / IC = (IB / IC) + 1
1 / Alpha = (1 / Beta) + 1 = (Beta + 1) / Beta
Inverting yields: Alpha = Beta / (Beta + 1)
Solving for Beta yields: Beta = Alpha / (1 - Alpha).

⚠️ EXAM PITFALL & CAUTION:

IE is always the LARGEST current in a BJT: IE = IB + IC. Collector current is slightly smaller than emitter current (Alpha < 1).

$$\text{Cutoff (OFF): } V_{in} = 0 \implies I_B = 0, \; I_C = 0, \; V_{CE} = V_{CC}$$

$$R_B = \frac{V_{in} - V_{BE,\text{sat}}}{I_B}$$
📝 STEP-BY-STEP MODEL SOLUTION:

- Cutoff (Switch OFF): When Vin = 0 V, Vbe < 0.7 V. Base current IB = 0, Collector current IC = 0. The transistor behaves as an open switch; full supply Vcc appears across C-E.

BJT vs FET / MOSFET Detailed Comparison

📌 PROBLEM / QUESTION:
Provide a comprehensive comparison between Bipolar Junction Transistors (BJT) and Field-Effect Transistors (FET / MOSFET) regarding carrier conduction, control mechanism, input impedance, thermal stability, and noise.
รูปประกอบ: Transistor BJT vs MOSFET Comparison
📐 KEY FORMULAS & DEFINITIONS:
$$\text{BJT: Bipolar (Holes + Electrons) } | \text{ Current-Controlled } (I_B) | R_{\text{in}} \approx 1 - 10\text{ k}\Omega$$
$$\text{MOSFET: Unipolar (Majority only) } | \text{ Voltage-Controlled } (V_{GS}) | R_{\text{in}} \approx 10^{12} - 10^{14}\,\Omega$$
📝 STEP-BY-STEP MODEL SOLUTION:

Comprehensive Comparison:
1. Carrier Conduction:
- BJT is BIPOLAR (current conduction involves both electrons and holes).
- MOSFET is UNIPOLAR (current conduction relies strictly on majority carriers in the channel).

2. Control Mechanism:
- BJT is CURRENT-CONTROLLED: Output current IC is controlled by input base current IB (IC = Beta * IB).
- MOSFET is VOLTAGE-CONTROLLED: Output drain current ID is controlled by gate-to-source voltage VGS.

3. Input Impedance:
- BJT: Low to moderate input impedance (1 k-ohm to 10 k-ohms) because the base-emitter junction is forward-biased.
- MOSFET: Near-infinite input impedance (10^12 to 10^14 ohms) due to the insulating silicon dioxide gate dielectric.

4. Thermal Stability:
- BJT has negative temperature coefficient for Vbe, making it vulnerable to Thermal Runaway.
- MOSFET has positive temperature coefficient for RDS(on), naturally preventing thermal runaway and allowing easy parallel operation.

⚠️ EXAM PITFALL & CAUTION:

BJT = Bipolar, Current-controlled, Low Rin. MOSFET = Unipolar, Voltage-controlled, Extremely high Rin.

Operational Amplifier (Op-Amp 741) Characteristics

📌 PROBLEM / QUESTION:
State the ideal characteristics of an Operational Amplifier (Op-Amp): input impedance, output impedance, open-loop gain, bandwidth, and slew rate. Explain the concept of Virtual Short / Virtual Ground.
📐 KEY FORMULAS & DEFINITIONS:
$$R_{\text{in}} = \infty \implies I_+ = I_- = 0$$
$$R_{\text{out}} = 0 \qquad A_{OL} = \infty \qquad \text{Bandwidth} = \infty$$
$$\text{Virtual Short: } V_+ \approx V_- \quad (\text{Under negative feedback})$$
$$\text{Inverting Gain: } A_v = -\frac{R_f}{R_{\text{in}}} \qquad \text{Non-inverting Gain: } A_v = 1 + \frac{R_f}{R_1}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Ideal Op-Amp Characteristics:
- Input Impedance (Rin): Infinite (no current enters the input terminals: I+ = I- = 0).
- Output Impedance (Rout): Zero (can supply any load current without internal voltage drop).
- Open-Loop Voltage Gain (A_OL): Infinite.
- Bandwidth (BW): Infinite (amplifies signals from DC to infinite frequency without attenuation).
- Slew Rate: Infinite (output changes voltage instantaneously).
- Common-Mode Rejection Ratio (CMRR): Infinite.

2. Virtual Short & Virtual Ground:
Because open-loop gain A_OL is infinite, in any negative feedback configuration, the differential input voltage MUST be zero:
(V+ - V-) = Vout / A_OL = Vout / infinity = 0 => V+ = V-.
This is called a 'Virtual Short'. If the non-inverting terminal V+ is tied to physical ground (0 V), then V- is held firmly at 0 V without being physically connected to ground, known as 'Virtual Ground'.

⚠️ EXAM PITFALL & CAUTION:

Virtual short (V+ = V-) holds ONLY when negative feedback is present. In an open-loop comparator, V+ is NOT equal to V-.
