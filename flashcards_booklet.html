Star (Y) vs Delta (Δ) Voltage & Current Relations

📌 PROBLEM / QUESTION:
In a balanced 3-phase positive-sequence ($abc$) system, state the exact relationships between line quantities ($V_L, I_L$) and phase quantities ($V_p, I_p$) for both Y-connection and $\Delta$-connection.
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Star (Y): } V_L = \sqrt{3}\, V_p \angle +30^\circ, \quad I_L = I_p$$
$$\text{Delta (}\Delta\text{): } V_L = V_p, \quad I_L = \sqrt{3}\, I_p \angle -30^\circ$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Star (Y) Connection:
- Line Voltage leads Phase Voltage by $30^\circ$:
$$V_{ab} = \sqrt{3}\, V_{an} \angle +30^\circ$$
- Line Current equals Phase Current:
$$I_L = I_p$$

2. Delta (Δ) Connection:
- Line Voltage equals Phase Voltage:
$$V_L = V_p$$
- Line Current lags Phase Current by $30^\circ$:
$$I_a = \sqrt{3}\, I_{ab} \angle -30^\circ$$

⚠️ EXAM PITFALL & CAUTION:

In negative sequence (acb), line voltage leads by -30° (or lags by 30°). Remember: in Y, currents are identical; in Δ, voltages are identical.

Delta to Wye (Δ ↔ Y) Impedance Conversion

📌 PROBLEM / QUESTION:
If a balanced $3\phi$ load is connected in $\Delta$ with impedance $Z_\Delta = 60 + j30\ \Omega$, what is the equivalent impedance per phase when converted to a Wye (Y) connection ($Z_Y$)?
📐 KEY FORMULAS & DEFINITIONS:
$Z_Y = \frac{Z_\Delta}{3}\quad \Leftrightarrow\quad Z_\Delta = 3 Z_Y$
📝 STEP-BY-STEP MODEL SOLUTION:

$$Z_Y = \frac{Z_\Delta}{3} = \frac{60 + j30}{3} = 20 + j10\ \Omega$$
Conversely, converting from Wye to Delta: $Z_\Delta = 3 Z_Y$.

⚠️ EXAM PITFALL & CAUTION:

Multiplying by 3 instead of dividing is a classic mistake! Delta load draws 3 times more current than Wye load of the same impedance, so equivalent Wye impedance must be 3 times smaller.

Three-Phase Power Formulas & Complex Power

📌 PROBLEM / QUESTION:
State the formulas for balanced $3\phi$ Real Power ($P_{3\phi}$), Reactive Power ($Q_{3\phi}$), Apparent Power ($|S_{3\phi}|$), and Complex Power ($S_{3\phi}$) in terms of line values ($V_L, I_L$).
📐 KEY FORMULAS & DEFINITIONS:
$P_{3\phi} = \sqrt{3}V_L I_L \cos\theta\quad [\text{W}]$ $Q_{3\phi} = \sqrt{3}V_L I_L \sin\theta\quad [\text{VAR}]$ $|S_{3\phi}| = \sqrt{3}V_L I_L\quad [\text{VA}]$ $S_{3\phi} = \sqrt{3}V_L I_L^* = P + jQ$
📝 STEP-BY-STEP MODEL SOLUTION:

When using Line values ($V_L, I_L$), always include the factor $\sqrt{3}$.
When using Phase values ($V_p, I_p$), use factor $3$:
- $P = 3 V_p I_p \cos\theta$
- $Q = 3 V_p I_p \sin\theta$
- $S = 3 V_p I_p^*$
where $\theta = \angle Z_p$ is the load phase impedance angle, and $PF = \cos\theta$.

⚠️ EXAM PITFALL & CAUTION:

Never mix $\sqrt{3}$ with phase quantities! It is either $\sqrt{3}V_L I_L$ or $3 V_p I_p$.

Balanced 4-Wire Y-Y System Full Calculation

📌 PROBLEM / QUESTION:
In the balanced Y-Y circuit shown below, source phase voltages are $V_{an} = 220\angle 0^\circ\text{ V}$, $V_{bn} = 220\angle -120^\circ\text{ V}$, $V_{cn} = 220\angle -240^\circ\text{ V}$. Line impedance $Z_{\text{line}} = 10 + j5\ \Omega$. Balanced load impedance $Z_L = 20 + j50\ \Omega$. Find: (1) Line voltages $V_{ab}, V_{bc}, V_{ca}$, (2) Line currents $I_{aA}, I_{bB}, I_{cC}$, (3) Neutral current $I_{Nn}$, (4) Total $3\phi$ complex power $S$.
รูปประกอบ: Homework 6 Figure 1: Balanced Y-Y System
📐 KEY FORMULAS & DEFINITIONS:
$V_{ab} = \sqrt{3}V_{an}\angle +30^\circ$ $I_{aA} = \frac{V_{an}}{Z_{\text{line}} + Z_L}$ $I_{Nn} = 0$ $S_{3\phi} = 3 V_{an} I_{aA}^*$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Line Voltages:
- $V_{ab} = \sqrt{3}(220)\angle (0^\circ + 30^\circ) = 381.05\angle 30^\circ\text{ V}$
- $V_{bc} = 381.05\angle -90^\circ\text{ V}$
- $V_{ca} = 381.05\angle -210^\circ\text{ V}$

2. Per-phase total impedance:
$$Z_{\text{total}} = (10 + j5) + (20 + j50) = 30 + j55\ \Omega = 62.65\angle 61.39^\circ\ \Omega$$

3. Line Currents:
- $I_{aA} = \frac{220\angle 0^\circ}{62.65\angle 61.39^\circ} = 3.51\angle -61.39^\circ\text{ A}$
- $I_{bB} = 3.51\angle -181.39^\circ\text{ A}$
- $I_{cC} = 3.51\angle 58.61^\circ\text{ A}$

4. Neutral Current:
In a balanced system, $I_{Nn} = 0\text{ A}$, $V_{Nn} = 0\text{ V}$.

5. Total $3\phi$ Power:
$$S = 3 \times 220 \times 3.51\angle +61.39^\circ = 2,316.6\angle 61.39^\circ\text{ VA} = 1,109\text{ W} + j2,034\text{ VAR}$$

⚠️ EXAM PITFALL & CAUTION:

Always remember to conjugate the current ($I^*$) when calculating complex power: $S = V I^*$. The angle of $S$ equals the angle of $Z$.

Unbalanced 4-Wire Y-Y System with Neutral Wire

📌 PROBLEM / QUESTION:
In the 4-wire Y-Y system shown below, the source is balanced $220\text{ V}$ rms, line impedance $Z_{\text{line}} = 10 + j5\ \Omega$, neutral line impedance $Z_{nN} = 10 + j5\ \Omega$, and the load is UNBALANCED: $Z_A = 20 + j50\ \Omega$, $Z_B = 10 + j50\ \Omega$, $Z_C = 20 + j20\ \Omega$. How do you solve for the Neutral Shift Voltage ($V_{Nn}$) and line currents?
รูปประกอบ: Homework 6 Figure 2: Unbalanced Y-Y 4-Wire with Neutral Line
📐 KEY FORMULAS & DEFINITIONS:
$$V_{Nn} = \frac{\frac{V_{an}}{Z_a'} + \frac{V_{bn}}{Z_b'} + \frac{V_{cn}}{Z_c'}}{\frac{1}{Z_a'} + \frac{1}{Z_b'} + \frac{1}{Z_c'} + \frac{1}{Z_{nN}}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Millman's / Node Voltage at Neutral node N:
Let node n be the reference ($0\text{ V}$).
Total phase branch impedances:
- $Z_a' = (10+j5) + (20+j50) = 30 + j55\ \Omega$
- $Z_b' = (10+j5) + (10+j50) = 20 + j55\ \Omega$
- $Z_c' = (10+j5) + (20+j20) = 30 + j25\ \Omega$
- $Z_{nN} = 10 + j5\ \Omega$

2. Solve for $V_{Nn}$ using KCL at node N:
$$\frac{V_N - V_{an}}{Z_a'} + \frac{V_N - V_{bn}}{Z_b'} + \frac{V_N - V_{cn}}{Z_c'} + \frac{V_N}{Z_{nN}} = 0$$

3. Calculate Line Currents:
- $I_{aA} = \frac{V_{an} - V_{Nn}}{Z_a'}$
- $I_{bB} = \frac{V_{bn} - V_{Nn}}{Z_b'}$
- $I_{cC} = \frac{V_{cn} - V_{Nn}}{Z_c'}$
- $I_{Nn} = \frac{V_{Nn}}{Z_{nN}} = I_{aA} + I_{bB} + I_{cC}$

⚠️ EXAM PITFALL & CAUTION:

Do NOT assume $V_{Nn} = 0$! In an unbalanced system, current flows through the neutral wire, causing a non-zero neutral shift voltage $V_{Nn} \neq 0$.

Unbalanced 3-Wire Y-Y System (NO Neutral Wire)

📌 PROBLEM / QUESTION:
In the 3-wire Y-Y system shown below (NO neutral wire), the load is unbalanced ($Z_A \neq Z_B \neq Z_C$). How is the neutral shift voltage $V_{Nn}$ calculated, and what happens to the neutral impedance term in the Millman formula?
รูปประกอบ: Homework 6 Figure 3: Unbalanced Y-Y 3-Wire System
📐 KEY FORMULAS & DEFINITIONS:
$$V_{Nn} = \frac{\frac{V_{an}}{Z_a'} + \frac{V_{bn}}{Z_b'} + \frac{V_{cn}}{Z_c'}}{\frac{1}{Z_a'} + \frac{1}{Z_b'} + \frac{1}{Z_c'}}$$ $$I_{aA} + I_{bB} + I_{cC} = 0$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Floating Neutral Point:
Because there is no neutral conductor, $Z_{nN} = \infty$, meaning the admittance term $\frac{1}{Z_{nN}} = 0$.

2. Node Voltage equation at N:
$$V_{Nn} = \frac{V_{an} Y_a' + V_{bn} Y_b' + V_{cn} Y_c'}{Y_a' + Y_b' + Y_c'}$$
where $Y_x' = \frac{1}{Z_x'}$.

3. Zero Neutral Current:
Without a neutral path, $I_{Nn} = 0$ strictly holds, which means:
$$I_{aA} + I_{bB} + I_{cC} = 0$$

⚠️ EXAM PITFALL & CAUTION:

Even though $I_{Nn} = 0$ (no physical wire), $V_{Nn}$ is NOT zero! The neutral point floats and shifts severely, subjecting some phases to dangerous overvoltages.

📌 HW Ch.6 Problem 4 (12 HP Y-Motor)

3-Phase Motor Input Power, Efficiency & Line Current

📌 PROBLEM / QUESTION:
A $3\phi, 12\text{-hp}$ induction motor is connected in Y to a balanced $380\text{ V}, 50\text{ Hz}$ supply. The motor has efficiency $\eta = 90\%$ and $PF = 0.85$ lagging. Calculate: (1) Input electrical power $P_{\text{in}}$, (2) Line current $I_L$, (3) Total complex power $S$, (4) Equivalent impedance per phase $Z_Y$.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{out}} = 12 \times 746\text{ W} = 8,952\text{ W}$$ $$P_{\text{in}} = \frac{P_{\text{out}}}{\eta}$$ $$I_L = \frac{P_{\text{in}}}{\sqrt{3} V_L \cdot PF}$$ $$S = \frac{P_{\text{in}}}{PF}\angle \arccos(PF)$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Convert output power to Watts:
$$P_{\text{out}} = 12 \times 746 = 8,952\text{ W}$$

2. Input Electrical Real Power:
$$P_{\text{in}} = \frac{8,952}{0.90} = 9,946.67\text{ W} \approx 9.95\text{ kW}$$

3. Line Current ($I_L$):
$$I_L = \frac{9,946.67}{\sqrt{3} \times 380 \times 0.85} = \frac{9,946.67}{559.45} = 17.78\text{ A}$$

4. Complex Power ($S$):
$$\theta = \arccos(0.85) = 31.79^\circ$$
$$|S| = \frac{9.946}{0.85} = 11.70\text{ kVA}$$
$$S = 11.70\angle 31.79^\circ\text{ kVA} = 9.95\text{ kW} + j6.16\text{ kVAR}$$

5. Per-Phase Impedance ($Z_Y$):
$$V_p = \frac{380}{\sqrt{3}} = 219.39\text{ V}$$
$$Z_Y = \frac{V_p}{I_L} = \frac{219.39}{17.78}\angle 31.79^\circ = 12.34\angle 31.79^\circ\ \Omega = 10.49 + j6.50\ \Omega$$
($R = 10.49\ \Omega$, $L = \frac{6.50}{2\pi \times 50} = 20.7\text{ mH}$)

⚠️ EXAM PITFALL & CAUTION:

Remember: $1\text{ hp} = 746\text{ W}$. Horsepower is ALWAYS mechanical output power at the shaft ($P_{\text{out}}$), never electrical input power ($P_{\text{in}}$)!

Delta-Connected 3-Phase Motor Analysis

📌 PROBLEM / QUESTION:
A $3\phi, 10\text{-hp}$ induction motor is connected in $\Delta$ to a $380\text{ V}, 50\text{ Hz}$ supply. $\eta = 85\%, PF = 0.80$ lagging. Find: (1) Input power $P_{\text{in}}$, (2) Line current $I_L$, (3) Phase winding current $I_\Delta$, (4) Phase impedance $Z_\Delta$.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{in}} = \frac{10 \times 746}{0.85}$$ $$I_L = \frac{P_{\text{in}}}{\sqrt{3} V_L PF}$$ $$I_\Delta = \frac{I_L}{\sqrt{3}}$$ $$Z_\Delta = \frac{V_L}{I_\Delta}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Input Power:
$$P_{\text{in}} = \frac{7,460\text{ W}}{0.85} = 8,776.47\text{ W} = 8.78\text{ kW}$$

2. Line Current:
$$I_L = \frac{8,776.47}{\sqrt{3} \times 380 \times 0.80} = 16.67\text{ A}$$

3. Delta Phase Current:
In $\Delta$, line current divides: $I_\Delta = \frac{I_L}{\sqrt{3}} = \frac{16.67}{1.732} = 9.62\text{ A}$

4. Impedance per phase ($Z_\Delta$):
In $\Delta$, $V_p = V_L = 380\text{ V}$.
$$|Z_\Delta| = \frac{V_p}{I_\Delta} = \frac{380}{9.62} = 39.50\ \Omega$$
$$\theta = \arccos(0.8) = 36.87^\circ$$
$$Z_\Delta = 39.50\angle 36.87^\circ\ \Omega = 31.60 + j23.70\ \Omega$$

⚠️ EXAM PITFALL & CAUTION:

In a Delta load, $V_p = V_L = 380\text{ V}$, but $I_p = I_L / \sqrt{3}$. Do not divide voltage by $\sqrt{3}$ for a Delta load!

Two-Wattmeter Method for 3-Phase Power Measurement

📌 PROBLEM / QUESTION:
In the two-wattmeter method measuring a balanced 3-phase load, state the equations for total real power ($P_{\text{total}}$), total reactive power ($Q_{\text{total}}$), and the load power factor angle ($\theta$) in terms of wattmeter readings $W_1$ and $W_2$.
📐 KEY FORMULAS & DEFINITIONS:
$$P_{\text{total}} = W_1 + W_2$$ $$Q_{\text{total}} = \sqrt{3}(W_1 - W_2)$$ $$\tan\theta = \sqrt{3}\frac{W_1 - W_2}{W_1 + W_2}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Total Active Power is simply the algebraic sum:
$$P = W_1 + W_2$$

2. Total Reactive Power is proportional to the difference:
$$Q = \sqrt{3}(W_1 - W_2)$$

3. Phase angle of the load:
$$\theta = \arctan\left(\sqrt{3}\frac{W_1 - W_2}{W_1 + W_2}\right)$$
$$PF = \cos\theta$$

Special Cases:
- If $PF = 1.0$: $W_1 = W_2$
- If $PF = 0.5$: One wattmeter reads zero ($W_2 = 0$)
- If $PF < 0.5$: One wattmeter reads NEGATIVE!

⚠️ EXAM PITFALL & CAUTION:

When $PF < 0.5$, one wattmeter reads negative! On an analog meter, reverse the current coil connections to read the value, then treat that reading as a negative number in $W_1 + W_2$.

Power Factor Correction with Delta Capacitors

📌 PROBLEM / QUESTION:
A balanced $3\phi$ inductive load of $30\text{ kW}$ operates at $380\text{ V}, 50\text{ Hz}$ with $PF_1 = 0.65$ lagging. What total reactive power $Q_C$ must a capacitor bank supply to improve the power factor to $PF_2 = 0.95$ lagging, and what is the capacitance per phase if connected in Delta ($C_\Delta$)?
📐 KEY FORMULAS & DEFINITIONS:
$$Q_C = P(\tan\theta_1 - \tan\theta_2)$$ $$C_\Delta = \frac{Q_{C,\text{phase}}}{\omega V_L^2} = \frac{Q_C / 3}{2\pi f V_L^2}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Find power factor angles:
- $\theta_1 = \arccos(0.65) = 49.46^\circ \Rightarrow \tan\theta_1 = 1.169$
- $\theta_2 = \arccos(0.95) = 18.19^\circ \Rightarrow \tan\theta_2 = 0.329$

2. Required 3-phase Reactive Power from Capacitors:
$$Q_C = 30\text{ kW} \times (1.169 - 0.329) = 30 \times 0.840 = 25.20\text{ kVAR}$$

3. Delta connection per-phase capacitance:
Each branch sees full line voltage $V_L = 380\text{ V}$ and supplies $Q_{C1} = \frac{25,200}{3} = 8,400\text{ VAR}$:
$$C_\Delta = \frac{8,400}{2\pi(50)(380)^2} = \frac{8,400}{314.16 \times 144,400} = 1.85 \times 10^{-4}\text{ F} = 185\ \mu\text{F}$$

⚠️ EXAM PITFALL & CAUTION:

Capacitors connected in Delta require 3 times LESS capacitance than Wye-connected capacitors ($C_\Delta = C_Y / 3$) for the same reactive power, saving massive physical space and cost!

📌 Final Exam Problem 4.4 (Page 27 - 8 Points)

3-Phase Induction Motor & Squirrel-Cage Rotor Operation

📌 PROBLEM / QUESTION:
Referring to the 3-phase induction motor diagram below: (1) What is a Squirrel-Cage Rotor and how does it work? (2) Explain the operating principle of a 3-phase induction motor. (3) How do you reverse its direction of rotation?
รูปประกอบ: Homework 7 Problem 4: DC Shunt Motor Equivalent Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$n_s = \frac{120 f}{P}$$ $$s = \frac{n_s - n_r}{n_s}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Squirrel-Cage Rotor (โรเตอร์แบบกรงกระรอก):
Consists of conducting aluminum/copper bars embedded in laminated iron core, short-circuited at both ends by end-rings. When the rotating magnetic field sweeps across the bars, it induces currents producing torque.

2. Operating Principle:
3-phase stator currents produce a Constant-Magnitude Rotating Magnetic Field (RMF) spinning at synchronous speed $n_s = 120f/P$. By Faraday-Lenz law, this field cuts rotor bars, inducing voltage and rotor currents. The interaction generates Lorentz torque, pulling the rotor in the direction of the rotating field.

3. Direction Reversal:
Swap ANY TWO supply phase lines (e.g., swap A and B, keeping C fixed). This reverses the phase sequence and rotates the RMF in the opposite direction.

⚠️ EXAM PITFALL & CAUTION:

The rotor can NEVER reach synchronous speed ($n_r < n_s$). If $n_r = n_s$, relative velocity is zero, no voltage is induced, and torque drops to zero!

DC Generator Principle & Commutator Rectification

📌 PROBLEM / QUESTION:
What machine is shown in the diagram below and how does it work? Explain how the split-ring commutator converts induced AC into pulsating DC at the output terminals.
รูปประกอบ: Homework 7 Problem 5: DC Series Motor Equivalent Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$e = B\ell v \sin\theta$$ $$E_a = k_a \phi \omega_m$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Identification:
Single-phase DC Generator with split-ring commutator.

2. Principle of Operation:
Mechanical power drives the coil rotating in the magnetic field between permanent magnet poles. By Faraday's Law, an alternating electromotive force ($e = B\ell v$) is induced inside the rotating coil.

3. Commutator Action:
The split-ring commutator mechanically reverses coil connections to the external stationary carbon brushes every half revolution, rectifying the internal alternating AC into unidirectional pulsating DC.

⚠️ EXAM PITFALL & CAUTION:

Inside ANY rotating DC armature, the induced voltage is ALWAYS AC! The commutator is what converts internal AC into external DC.

Synchronous Motor Operation, V-Curve & Power Factor Correction

📌 PROBLEM / QUESTION:
Why does a Synchronous Motor rotate at exactly synchronous speed with zero slip ($s=0$)? How does varying its DC field excitation current ($I_f$) allow it to act as a Synchronous Condenser to correct facility power factor?
📐 KEY FORMULAS & DEFINITIONS:
$$n_r = n_s = \frac{120f}{P}$$ Normal excitation: $PF = 1.0$ Over-excitation: Leading $PF$ (supplies Q) Under-excitation: Lagging $PF$ (draws Q)
📝 STEP-BY-STEP MODEL SOLUTION:

1. Constant Synchronous Speed:
The rotor's DC-excited poles lock magnetically into synchronism with the stator's rotating magnetic field. As long as load does not exceed pull-out torque, it runs at precisely $n_s$.

2. V-Curve & Power Factor Control:
- Under-excited ($I_f$ small): Motor draws lagging reactive power ($Q > 0$).
- Normal excitation: Motor operates at unity power factor ($PF = 1.0$), minimum stator current.
- Over-excited ($I_f$ large): Motor draws leading reactive power (acts as a capacitor, supplying VARs to the grid to correct factory power factor).

⚠️ EXAM PITFALL & CAUTION:

Synchronous motors are NOT inherently self-starting from a dead stop because the stator RMF moves past stationary rotor poles too fast for inertia to catch up. They require damper (amortisseur) windings to start as an induction motor first.

DC Motor Starting Current & Starting Resistor Design

📌 PROBLEM / QUESTION:
Why is the starting current of a DC motor dangerously high (10 to 20 times rated current) if started directly on full voltage? How does an external starting resistor protect the motor?
📐 KEY FORMULAS & DEFINITIONS:
At start ($n=0$): $E_a = 0$ $$I_{\text{start}} = \frac{V_t}{R_a}$$ With starter: $$I_{\text{start}} = \frac{V_t}{R_a + R_{\text{start}}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Why Starting Current is Enormous:
At standstill ($n = 0$), back EMF $E_a = k_a \phi \omega_m = 0\text{ V}$. Because armature resistance $R_a$ is designed to be tiny ($< 0.5\ \Omega$) for high efficiency:
$$I_{\text{start}} = \frac{V_t - 0}{R_a} = \frac{220\text{ V}}{0.5\ \Omega} = 440\text{ A}!$$
This burns the armature coils and melts commutator brushes.

2. Protection via Starting Resistor:
A multi-step starting resistance $R_{\text{start}}$ is placed in series with the armature to limit starting current to $1.5 - 2.0 \times I_{\text{rated}}$. As the motor accelerates and builds up $E_a$, resistance steps are cut out.

⚠️ EXAM PITFALL & CAUTION:

Never start a DC motor under full voltage without starting resistance (except tiny sub-fractional HP motors).

📌 PROBLEM / QUESTION:

- Hysteresis loss ($P_h \propto f B_{\max}^{1.6}$) + Eddy current loss ($P_e \propto f^2 B_{\max}^2 t^2$).
- Constant 24/7: Depends only on applied voltage and frequency; independent of load current!

2. Copper Loss ($I^2 R$ Loss / การสูญเสียในขดลวดทองแดง):
- Caused by Joule heating in primary and secondary winding resistances.
- Variable: Proportional to the square of load current ($P_{\text{cu}} \propto I_L^2$). Zero at no load!

⚠️ EXAM PITFALL & CAUTION:

Maximum transformer efficiency occurs when Variable Loss equals Constant Loss: $P_{\text{cu}} = P_{\text{core}}$!

Audio Transformer Impedance Matching for Maximum Power Transfer

📌 PROBLEM / QUESTION:
A $10\text{ V}$ audio source with internal source resistance $R_s = 1\ \Omega$ is connected to a speaker load $R_L = 9\ \Omega$. (a) Find power to the speaker without transformer. (b) If an ideal matching transformer with turns ratio $a = 1/3$ is inserted, find the new power transferred to the speaker.
รูปประกอบ: Audio Transformer Maximum Power Transfer Impedance Matching
📐 KEY FORMULAS & DEFINITIONS:
$$R_L' = a^2 R_L = \left(\frac{N_1}{N_2}\right)^2 R_L$$ Maximum Power Transfer when $R_L' = R_s$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Without Transformer:
$$I = \frac{10}{1 + 9} = 1.0\text{ A}$$
$$P_{\text{speaker}} = I^2 R_L = (1.0)^2 \times 9 = 9.0\text{ W}$$

2. With Transformer ($a = 1/3$):
Reflected load resistance seen by source:
$$R_L' = a^2 R_L = \left(\frac{1}{3}\right)^2 \times 9 = \frac{1}{9} \times 9 = 1.0\ \Omega$$
Notice $R_L' = R_s = 1.0\ \Omega$ (perfect Maximum Power Transfer match!).
New primary current:
$$I_1 = \frac{10}{1 + 1} = 5.0\text{ A}$$
Power delivered to reflected load (and thus speaker):
$$P_{\text{speaker}} = I_1^2 R_L' = (5.0)^2 \times 1.0 = 25.0\text{ W}$$
Power increases dramatically from $9\text{ W}$ to $25\text{ W}$!

Transformer Voltage Regulation Formula & Power Factor Dependency

📌 PROBLEM / QUESTION:
State the formula for Transformer Voltage Regulation ($VR\%$). How does the power factor (lagging vs leading) affect voltage regulation, and can $VR\%$ ever be negative?
📐 KEY FORMULAS & DEFINITIONS:
$$VR\% = \frac{V_{NL} - V_{FL}}{V_{FL}} \times 100\%$$ Approx: $$VR\% \approx \frac{I_2 R_{eq2} \cos\theta \pm I_2 X_{eq2} \sin\theta}{V_2} \times 100\%$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Formula:
$$VR\% = \frac{V_{2,NL} - V_{2,FL}}{V_{2,FL}} \times 100\%$$

2. Effect of Power Factor:
- Lagging PF (Inductive load): (+) sign applies. Voltage drops under load ($V_{FL} < V_{NL}$), so $VR\% > 0$ (positive).

Auto-Transformer Principle, Higher kVA Rating & Common Winding Risk

📌 PROBLEM / QUESTION:
What is an Auto-Transformer? Why does it possess a higher kVA power rating and higher efficiency than a conventional two-winding transformer of the same physical size, and what is its primary safety drawback?
📐 KEY FORMULAS & DEFINITIONS:
$$\frac{S_{\text{auto}}}{S_{\text{2-w}}} = \frac{1}{1 - 1/a_{\text{auto}}}$$
$$S_{\text{auto}} = S_{\text{conducted}} + S_{\text{transformed}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Construction & Principle:
An auto-transformer has a SINGLE continuous winding shared partly by both primary and secondary circuits (tapped common winding).

2. Higher Rating & Efficiency:
Power is transferred via two mechanisms simultaneously:
- By direct electrical conduction ($S_{\text{conducted}} = V_2 I_1$)
- By electromagnetic induction ($S_{\text{transformed}} = V_2 (I_2 - I_1)$)
Because a large fraction of power flows conductively without transforming through magnetic flux:
$$\frac{S_{\text{auto}}}{S_{\text{2-w}}} = \frac{1}{1 - 1/a} > 1$$
Core and windings are much smaller, dramatically lowering $I^2 R$ heat loss and core losses.

3. Safety Drawback:
NO ELECTRICAL ISOLATION between primary (HV) and secondary (LV)! If the common ground connection opens, the full high voltage appears directly on the low voltage terminals, risking electrocution.

⚠️ EXAM PITFALL & CAUTION:

Never use an autotransformer where human safety isolation from high voltage mains is required (e.g. medical equipment or bathroom supplies).

Power Transmission Loss Formula & High-Voltage Economics

📌 PROBLEM / QUESTION:
Derive the mathematical relationship between transmission line voltage $V_L$, line current $I_L$, and $I^2 R$ power losses for transmitting real power $P$. Explain quantitatively why stepping up voltage by 10 times dramatically reduces conductor losses and cross-sectional material costs.
📐 KEY FORMULAS & DEFINITIONS:
$$I_L = \frac{P}{\sqrt{3}\, V_L \cos\theta}$$
$$P_{\text{loss}} = 3 I_L^2 R_{\text{line}} = 3 \left(\frac{P}{\sqrt{3}\, V_L \cos\theta}\right)^2 R_{\text{line}} = \frac{P^2 R_{\text{line}}}{V_L^2 \cos^2\theta}$$
$$P_{\text{loss}} \propto \frac{1}{V_L^2}, \qquad \Delta V = \sqrt{3}\, I_L (R\cos\theta + X\sin\theta) \propto \frac{1}{V_L}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Derivation of Line Current:
For a balanced 3-phase line transmitting active power $P$ at power factor $\cos\theta$:
$$P = \sqrt{3}\, V_L I_L \cos\theta \implies I_L = \frac{P}{\sqrt{3}\, V_L \cos\theta}$$

2. Line Losses ($P_{\text{loss}}$):
Total Joule heating loss across all 3 phases:
$$P_{\text{loss}} = 3 I_L^2 R_{\text{line}} = \frac{P^2 R_{\text{line}}}{V_L^2 \cos^2\theta}$$

3. Quantitative Impact of 10x Voltage Step-Up:
- Line current $I_L$ decreases to $\frac{1}{10}$ (10 times smaller).
- Line power loss $P_{\text{loss}}$ decreases by $10^2 = 100$ times (99% reduction in loss!).
- Conductor cross-sectional area $A$ required to carry $I_L$ decreases proportionally, drastically cutting copper/aluminum conductor mass and tower structural weight.

⚠️ EXAM PITFALL & CAUTION:

Transmission losses depend inversely on the SQUARE of line voltage ($1/V_L^2$), while voltage drop $\Delta V$ is inversely proportional to $V_L$.

Hydraulic Turbine Classifications: Pelton, Francis & Kaplan

📌 PROBLEM / QUESTION:
Classify the 3 major types of hydraulic turbines (Pelton, Francis, Kaplan) by working principle, water head ($H$), flow rate ($Q$), and their engineering applications in hydroelectric dams.
รูปประกอบ: Slide 20: Three Hydraulic Turbine Types (Kaplan, Francis, Pelton)
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Pelton (Impulse): High Head } (H > 300\text{ m}), \quad \text{Low Flow Rate } (Q)$$
$$\text{Francis (Reaction): Medium Head } (30\text{ m} \le H \le 300\text{ m}), \quad \text{Medium Flow Rate } (Q)$$
$$\text{Kaplan (Propeller): Low Head } (H < 30\text{ m}), \quad \text{High Flow Rate } (Q)$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Pelton Turbine (Impulse Turbine / กังหันแรงกระแทก):
- Operating Principle: High-velocity water jets from nozzles strike cup-shaped buckets on the runner periphery in open air.
- Operating Conditions: High Head ($H > 300\text{ m}$) and Low Flow Rate ($Q$).
- Typical Application: High mountainous dams with steep waterfalls.

2. Francis Turbine (Reaction Turbine / กังหันแรงสะท้อน):
- Operating Principle: Water enters the runner radially under pressure through wicket gates and discharges axially.
- Operating Conditions: Medium Head ($30\text{ m} \le H \le 300\text{ m}$) and Medium Flow Rate ($Q$).
- Typical Application: Most widely used turbine globally, applied in large multi-purpose dams (e.g. Bhumibol Dam, Srinagarind Dam).

3. Kaplan Turbine (Propeller Reaction Turbine / กังหันแบบใบพัด):
- Operating Principle: Axial-flow propeller runner with adjustable blades (pitch control) to maintain high efficiency over variable flow rates.
- Operating Conditions: Low Head ($H < 30\text{ m}$) and High Flow Rate ($Q$).
- Typical Application: River run-of-river dams and low-head barrages (e.g. Chao Phraya Dam).

⚠️ EXAM PITFALL & CAUTION:

Pelton = High Head, Low Flow. Francis = Medium Head/Flow (most common). Kaplan = Low Head, High Flow (adjustable propeller).

Transmission Towers, Tower Footing Resistance & Lightning Protection

📌 PROBLEM / QUESTION:
Classify high-voltage transmission towers into Suspension, Tension, Dead-end, and Transposition towers. Define Tower Footing Resistance ($R_{\text{tower}}$), state why it must be maintained $\le 10\;\Omega$, and explain the Back Flashover phenomenon.
รูปประกอบ: High-Voltage Transmission Towers (Suspension, Tension, Transposition)
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Suspension (เสาแขวน): Straight route} \quad | \quad \text{Tension (เสารั้ง): Route angles/corners}$$
$$\text{Dead-end (เสาปลายสาย): Substation terminations} \quad | \quad \text{Transposition (เสาสลับเฟส): Phase balance}$$
$$R_{\text{tower}} \le 10\;\Omega, \qquad V_{\text{tower top}} = I_{\text{lightning}} \times R_{\text{tower}} + L \frac{di}{dt}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Transmission Tower Classifications:
- Suspension Towers (เสาแขวน): Used along straight paths. Insulators hang vertically to support the physical weight of conductors.
- Tension / Angle Towers (เสารั้ง/เสามุม): Used at line bends and angles. Insulator strings are positioned horizontally under heavy mechanical tension.
- Dead-end Towers (เสาปลายสาย): Heavy-duty termination towers situated just outside substations to withstand full one-sided mechanical tension.
- Transposition Towers (เสาสลับเฟส): Rotates phase conductor spatial positions by 120 degrees at regular 1/3 distance intervals to balance line inductances, capacitances, and phase voltages.

2. Tower Footing Resistance ($R_{\text{tower}}$):
- Definition: The electrical contact resistance between the steel tower footing ground grid and the earth mass.
- Standard Requirement: Must be maintained strictly below $10\;\Omega$.

3. Back Flashover Phenomenon:
- When lightning strikes the overhead shield wire (OHGW) or tower peak, huge surge current ($I_{\text{lightning}} \approx 50-100\text{ kA}$) flows down the steel tower to earth.
- Tower top voltage surges to $V_{\text{tower}} = I_{\text{lightning}} \times R_{\text{tower}}$.
- If $R_{\text{tower}} > 10\;\Omega$, $V_{\text{tower}}$ exceeds the impulse flashover rating of the insulator strings, causing an electrical arc to jump from the tower back into the phase conductors (Back Flashover), tripping circuit breakers.

⚠️ EXAM PITFALL & CAUTION:

Back Flashover occurs from tower to line when footing resistance is too high ($> 10\;\Omega$). Keep $R_{\text{tower}} \le 10\;\Omega$ with ground rods or counterpoise wires.

PMMC / Galvanometer Working Principle & Deflection Torque

📌 PROBLEM / QUESTION:
Explain the operating principle of a Permanent Magnet Moving Coil (PMMC / D'Arsonval) instrument. State the formulas for deflecting torque and controlling torque, and explain why PMMC instruments measure only DC directly.
📐 KEY FORMULAS & DEFINITIONS:
$$T_d = B \cdot I \cdot N \cdot A = G \cdot I$$
$$T_c = C \cdot \theta$$
$$\text{At equilibrium: } T_d = T_c \implies \theta = \left(\frac{B \cdot N \cdot A}{C}\right) I \propto I$$
$$I_{\text{avg, AC}} = \frac{1}{T} \int_0^T I_m \sin(\omega t)\, dt = 0$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Operating Principle:
A rectangular coil with $N$ turns and cross-sectional area $A$ carrying current $I$ is suspended in the uniform radial magnetic field $B$ of a permanent magnet. The interaction between current and magnetic flux produces a Lorentz force ($F = I L B$), resulting in a deflecting torque $T_d$:
$$T_d = B \cdot I \cdot N \cdot A = G \cdot I$$
where $G = B N A$ is the galvanometer constant.

2. Controlling Torque & Linear Scale:
A spiral hairspring produces an opposing restoring torque $T_c$:
$$T_c = C \cdot \theta$$
where $C$ is the spring constant and $\theta$ is the angular deflection. At equilibrium ($T_d = T_c$):
$$\theta = \left(\frac{B \cdot N \cdot A}{C}\right) I = \left(\frac{G}{C}\right) I$$
Because $B, N, A$, and $C$ are constants, the pointer deflection angle $\theta$ is directly proportional to current $I$ ($\theta \propto I$). This guarantees an evenly spaced, completely linear scale.

3. Why Measures Only DC Directly:
If connected to sinusoidal alternating current ($i(t) = I_m \sin\omega t$), torque alternates direction every half-cycle (50 Hz). Due to the mechanical inertia of the moving coil assembly, the pointer cannot track 50 Hz oscillations and responds strictly to the time-average value:
$$I_{\text{avg}} = \frac{1}{T} \int_0^T I_m \sin(\omega t)\, dt = 0$$
The pointer vibrates negligibly around zero. To measure AC, a diode rectifier must be placed before the PMMC movement.

⚠️ EXAM PITFALL & CAUTION:

PMMC measures strictly average DC. To measure AC with a PMMC meter, a rectifier circuit (diodes) must be added beforehand.

DC Ammeter Design with and without CDRX

📌 PROBLEM / QUESTION:
A Galvanometer has internal resistance Rg = 50 ohms, full-scale current Ig = 10 mA, and Critical Damping Resistance CDRX = 400 ohms. Design a DC Ammeter to measure full scale I = 100 mA for: (a) Pure circuit without CDRX (b) Circuit with CDRX (damping resistor).
รูปประกอบ: Homework 10 Problem 2: DC Ammeter Design with and without CDRX
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Without CDRX: } R_{\text{sh}} = \frac{I_g R_g}{I - I_g} = \frac{R_g}{m - 1}$$
$$\text{With CDRX: Series resistor } R_s = \text{CDRX} - R_g = 400 - 50 = 350\;\Omega$$
$$R_{\text{branch}} = R_g + R_s = \text{CDRX} = 400\;\Omega$$
$$R_{\text{sh}}' = \frac{I_g \cdot R_{\text{branch}}}{I - I_g} = \frac{I_g \cdot \text{CDRX}}{I - I_g}$$
$$R_{\text{in}} = R_{\text{sh}}' \parallel R_{\text{branch}}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Part (a) Without CDRX:
Shunt current bypassing the coil:
$$I_{\text{sh}} = I - I_g = 100\text{ mA} - 10\text{ mA} = 90\text{ mA} = 0.090\text{ A}$$
Shunt resistor $R_{\text{sh}}$:
$$R_{\text{sh}} = \frac{I_g \cdot R_g}{I - I_g} = \frac{(0.010\text{ A})(50\;\Omega)}{0.090\text{ A}} = \frac{0.50}{0.090} = 5.556\;\Omega$$

2. Part (b) With Critical Damping Resistance (CDRX = 400 ohms):
To ensure critical damping in an ammeter, insert a series damping resistor $R_s$ in the galvanometer branch:
$$R_s = \text{CDRX} - R_g = 400\;\Omega - 50\;\Omega = 350\;\Omega$$
Effective meter branch resistance:
$$R_{\text{branch}} = R_g + R_s = 400\;\Omega$$
New shunt resistor $R_{\text{sh}}'$:
$$R_{\text{sh}}' = \frac{I_g \cdot R_{\text{branch}}}{I - I_g} = \frac{(0.010\text{ A})(400\;\Omega)}{0.090\text{ A}} = \frac{4.0}{0.090} = 44.444\;\Omega$$
Total ammeter input resistance:
$$R_{\text{in}} = R_{\text{sh}}' \parallel R_{\text{branch}} = \frac{(44.444)(400)}{44.444 + 400} = 40.0\;\Omega$$

⚠️ EXAM PITFALL & CAUTION:

In Ammeters, CDRX requires a SERIES resistor Rs. Do not connect CDRX in parallel with Rg!

$$R_s = R_{\text{total}} - R_g = 5,000\;\Omega - 50\;\Omega = 4,950\;\Omega = 4.95\text{ k}\Omega$$

2. Part (b) With Critical Damping Resistance (CDRX = 400 ohms):
For a voltmeter, connect damping resistor $R_p = \text{CDRX} = 400\;\Omega$ in PARALLEL across the meter movement:
- Voltage drop across coil at full scale:
$$V_m = I_g \cdot R_g = (0.010\text{ A})(50\;\Omega) = 0.5\text{ V}$$
- Current drawn by parallel damping resistor $R_p$:
$$I_p = \frac{V_m}{R_p} = \frac{0.5\text{ V}}{400\;\Omega} = 1.25\text{ mA} = 0.00125\text{ A}$$
- Total current entering the voltmeter:
$$I_{\text{total}} = I_g + I_p = 10\text{ mA} + 1.25\text{ mA} = 11.25\text{ mA} = 0.01125\text{ A}$$
- Multiplier series resistor $R_s'$:
$$R_s' = \frac{V - V_m}{I_{\text{total}}} = \frac{50\text{ V} - 0.5\text{ V}}{0.01125\text{ A}} = \frac{49.5\text{ V}}{0.01125\text{ A}} = 4,400\;\Omega = 4.4\text{ k}\Omega$$
- Voltmeter sensitivity:
$$S = \frac{1}{I_{\text{total}}} = \frac{1}{0.01125\text{ A}} = 88.89\;\Omega/\text{V}$$

In Ammeters, CDRX requires a SERIES resistor Rs. In Voltmeters, CDRX requires a PARALLEL resistor Rp! Remember this contrast.

Ayrton Shunt (Universal Shunt) for Multi-Range Ammeter

📌 PROBLEM / QUESTION:
What is an Ayrton Shunt (Universal Shunt)? Why is it superior to individual switched shunts, and how do you calculate the resistor values Ra, Rb, and Rc for multi-range operation?
รูปประกอบ: Ayrton / Universal Shunt Multi-Range Ammeter Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$\text{Total Shunt: } R_{\text{sh}} = R_a + R_b + R_c$$
$$\text{Range 1 (Lowest } I_1\text{): } R_{\text{sh}} = \frac{I_{\text{fsd}} R_m}{I_1 - I_{\text{fsd}}}$$
$$\text{Range 2 (Medium } I_2\text{): } (R_b + R_c) = \frac{I_{\text{fsd}} (R_m + R_a)}{I_2}$$
$$\text{Range 3 (Highest } I_3\text{): } R_c = \frac{I_{\text{fsd}} (R_m + R_a + R_b)}{I_3}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. What is an Ayrton Shunt:
A tapped series chain of resistors ($R_a + R_b + R_c$) permanently connected in parallel across the meter movement $R_m$. Switching ranges moves the circuit input tap, altering which resistors act as shunt and which are added in series with the meter coil.

2. Decisive Advantage Over Individual Shunts:
- Make-Before-Break Safety: In individual shunts, if the rotary switch momentarily opens between contacts, the entire line current would blast through the fragile meter movement ($R_m$), destroying it instantly.
- In Ayrton shunt, the meter movement is NEVER left open without a parallel bypass path during range switching.

3. Equations for 3 Ranges:
- Lowest current $I_1$:
$$R_a + R_b + R_c = \frac{I_{\text{fsd}} R_m}{I_1 - I_{\text{fsd}}}$$
- Medium current $I_2$:
$$R_b + R_c = \frac{I_{\text{fsd}} (R_m + R_a)}{I_2}$$
- Highest current $I_3$:
$$R_c = \frac{I_{\text{fsd}} (R_m + R_a + R_b)}{I_3}$$

⚠️ EXAM PITFALL & CAUTION:

In Ayrton shunt calculations, the resistors not acting as shunt become added in series with Rm! Keep track of which resistors are in parallel vs in series.

A meter has Rm = 100 ohms and Ifsd = 50 microamperes. Calculate the multiplier resistor values R1, R2, and R3 to construct a multi-range voltmeter for 10 V, 50 V, and 250 V using a tapped series multiplier configuration.

Series-Type Ohmmeter Working Principle & Scale

📌 PROBLEM / QUESTION:
Explain the circuit design of a Series-Type Ohmmeter. Describe its pointer deflection at Rx = 0, Rx = R_half, and Rx = infinity, and explain why its resistance scale is non-linear and reads backwards.
รูปประกอบ: Series-Type Ohmmeter Circuit & Scale
📐 KEY FORMULAS & DEFINITIONS:
$$I = \frac{E}{R_{\text{in}} + R_x}$$
$$R_x = 0 \implies I = I_{\text{fsd}} = \frac{E}{R_{\text{in}}} \quad (\text{Far Right: } 0\;\Omega)$$
$$R_x = R_h = R_{\text{in}} \implies I = 0.5\, I_{\text{fsd}} \quad (\text{Center of scale: } R_h)$$
$$R_x = \infty \implies I = 0 \quad (\text{Far Left zero current: } \infty\;\Omega)$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Circuit Topology:
An internal battery $E$, current-limiting resistor $R_1$, zero-adjust rheostat $R_2$, and galvanometer $R_m$ are all connected in series with the unknown resistance $R_x$ across test terminals.

2. Scale Deflection Points:
- $R_x = 0$ (Short Circuit): Maximum current flows, deflecting pointer to full-scale at the far RIGHT:
$$I = I_{\text{fsd}} = \frac{E}{R_{\text{in}}} \implies 0\;\Omega$$
- $R_x = R_{\text{in}} = R_h$ (Half-Scale Resistance): Total resistance doubles, halving current to exactly mid-scale:
$$I = \frac{E}{2 R_{\text{in}}} = 0.5\, I_{\text{fsd}} \implies R_h$$
- $R_x = \infty$ (Open Circuit): No current flows, pointer remains at rest at far LEFT:
$$I = 0 \implies \infty\;\Omega$$

3. Why Scale is Non-Linear & Reads Backwards:
Because current $I = E / (R_{\text{in}} + R_x)$ varies inversely with $R_x$, deflection is hyperbolic. Markings are widely spaced on the right (low ohms) and heavily compressed on the left (high ohms).

⚠️ EXAM PITFALL & CAUTION:

Series ohmmeter scale reads 0 on the RIGHT and infinity on the LEFT (opposite to voltmeters and ammeters).

Shunt-Type Ohmmeter for Low Resistance Measurement

📌 PROBLEM / QUESTION:
Explain the operating principle of a Shunt-Type Ohmmeter. For what range of resistance is it suited, and how does its scale direction differ from a series ohmmeter?
รูปประกอบ: Shunt-Type Ohmmeter Circuit & Scale
📐 KEY FORMULAS & DEFINITIONS:
$$I_m = I_{\text{total}} \cdot \frac{R_x}{R_m + R_x}$$
$$R_x = 0 \implies I_m = 0 \quad (\text{Far Left edge = } 0\;\Omega)$$
$$R_x = R_m \implies I_m = 0.5\, I_{\text{total}} \quad (\text{Center of scale = } R_m)$$
$$R_x = \infty \implies I_m = I_{\text{fsd}} \quad (\text{Far Right edge = } \infty\;\Omega)$$
$$\text{Measurement range: Low resistance } (5\;\text{m}\Omega - 100\;\Omega)$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Operating Principle:
The unknown resistor $R_x$ is connected in PARALLEL (shunt) across the meter movement $R_m$, rather than in series. A series battery and resistor supply constant circuit current.

2. Scale Deflection Points:
- $R_x = 0$ (Short Circuit): All current bypasses through the zero-ohm short; coil current $I_m = 0$. Pointer stays at far LEFT = $0\;\Omega$:
$$I_m = 0 \implies 0\;\Omega$$
- $R_x = R_m$: Current splits equally; pointer deflects to mid-scale ($0.5 I_{\text{fsd}}$) = $R_m$.
- $R_x = \infty$ (Open Circuit): No current bypassed; full current flows through $R_m$, deflecting pointer to far RIGHT = $\infty\;\Omega$:
$$I_m = I_{\text{fsd}} \implies \infty\;\Omega$$
Result: Shunt ohmmeter scale reads from LEFT TO RIGHT ($0$ on left, $\infty$ on right), matching normal voltmeter/ammeter scale direction!

3. Primary Application:
Measuring very LOW resistances ($0.01\;\Omega$ to a few tens of ohms), such as motor winding coils, contact resistance, and transformer wire.

⚠️ EXAM PITFALL & CAUTION:

Series ohmmeter: 0 is on the RIGHT. Shunt ohmmeter: 0 is on the LEFT. Always know which type the question asks!

📌 PROBLEM / QUESTION:
What is the primary function of the Zero-Adjust Rheostat (Zero-Ohm Adjust) in an analog multimeter, and how do multi-range multipliers (Rx1, Rx10, Rx10k) scale the center-scale resistance Rh?

A PMMC instrument is used with a full-wave bridge rectifier to measure sinusoidal AC voltage. Derive the relationship between the meter's DC response and the AC RMS voltage, and explain what happens if a square wave or triangular wave is measured.

$$V_{\text{avg}} = \frac{2}{\pi} V_m \approx 0.637\, V_m$$
$$V_{\text{rms}} = \frac{V_m}{\sqrt{2}} \approx 0.707\, V_m$$

Wattmeter Connection to Load (Current vs Potential Coils)

📌 PROBLEM / QUESTION:
Describe the construction of an Electrodynamometer Wattmeter. How are the Current Coil (CC) and Potential/Voltage Coil (PC) connected to a load, and what precautions prevent coil burnout?
รูปประกอบ: Exam Problem 3.4: Electrodynamometer Wattmeter Connection to Load
📐 KEY FORMULAS & DEFINITIONS:
$$P = V_{\text{load}} \cdot I_{\text{load}} \cdot \cos\theta$$
$$\text{Current Coil (CC): Fixed, thick wire, low turns } \implies \text{Connected in SERIES with load (Terminals 1--2)}$$
$$\text{Potential Coil (PC): Moving, fine wire, high turns } \implies \text{Connected in PARALLEL across load (Terminals 3--5)}$$
$$\text{Burnout Hazard: Connecting CC in parallel creates a dead short circuit } I_{\text{sc}} = \frac{V}{R_{\text{CC}}} \approx \infty$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Wattmeter Coils & Connection:
- Current Coil (CC / ขดลวดกระแส): Made of thick copper wire with few turns (near-zero impedance). MUST be connected in SERIES with the load (terminals 1-2) to carry full line current.
- Potential Coil (PC / ขดลวดแรงดัน): Made of fine wire with many turns, connected in series with a high non-inductive multiplier resistance. MUST be connected in PARALLEL across the load terminals (terminals 3-5) to measure voltage.

2. Power Indication:
Instantaneous torque is proportional to the product of magnetic fields produced by both coils: $T_d \propto i_{\text{cc}}(t) \cdot i_{\text{pc}}(t)$, deflecting the pointer to indicate true real average active power:
$$P = V_{\text{load}} \cdot I_{\text{load}} \cdot \cos\theta$$

3. Burnout Hazard:
NEVER connect the Current Coil (CC) in parallel across the voltage supply! Because CC has near-zero resistance, connecting it in parallel creates an immediate dead short circuit ($I_{\text{sc}} = V / R_{\text{CC}} \approx \infty$), vaporizing the coil instantly.

⚠️ EXAM PITFALL & CAUTION:

Current Coil connects in SERIES. Potential Coil connects in PARALLEL. Reversing this causes explosive short circuits or an inoperative meter.

Energy Meter (Kilowatt-Hour Meter) Function

📌 PROBLEM / QUESTION:
Explain the working principle of an induction-type Kilowatt-Hour Meter (kWh meter). What creates the driving torque on the aluminum disc, and what is the role of the permanent brake magnet?
📐 KEY FORMULAS & DEFINITIONS:
$$T_d \propto V \cdot I \cdot \cos\theta = P$$
$$T_b \propto \omega \quad (\text{Eddy-current braking})$$
$$\text{At steady speed: } T_d = T_b \implies \omega \propto P$$
$$\text{Total Revolutions } N = \int \omega\, dt \propto \int P\, dt = \text{Energy (kWh)}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Driving Torque Generation:
The meter contains a shunt electromagnet (connected across line voltage) and a series electromagnet (carrying load current). Their alternating magnetic fluxes induce eddy currents inside a lightweight aluminum disc. The interaction between each eddy current and the alternating flux produces a continuous rotational driving torque $T_d$ proportional to instantaneous real power $P$:
$$T_d \propto V \cdot I \cdot \cos\theta = P$$

2. Braking Magnet Role:
A C-shaped permanent magnet sits near the outer edge of the disc. As the disc spins through this stationary field, eddy currents are induced in the disc, creating a retarding braking torque $T_b$ directly proportional to rotational speed $\omega$:
$$T_b \propto \omega$$

3. Energy Integration:
Equating driving and braking torque ($T_d = T_b$) yields:
$$\omega \propto P$$
The total number of disc revolutions $N$ over time is directly proportional to cumulative electrical energy in kilowatt-hours (kWh):
$$N = \int \omega\, dt \propto \int P\, dt = \text{Energy (kWh)}$$

⚠️ EXAM PITFALL & CAUTION:

The disc speed is proportional to POWER (kW), but the total number of revolutions is proportional to ENERGY (kWh).

Intrinsic vs Extrinsic, N-Type vs P-Type Semiconductors

📌 PROBLEM / QUESTION:
Distinguish between Intrinsic and Extrinsic semiconductors. Explain how N-Type and P-Type semiconductors are formed by doping, identifying the majority and minority charge carriers in each.
รูปประกอบ: Exam Problem 4.1: Intrinsic & Extrinsic Semiconductors
📐 KEY FORMULAS & DEFINITIONS:
$$\text{N-Type: Si (4 val) + Pentavalent (5 val: P, As, Sb) } \implies \text{Majority: Free Electrons } (e^-)$$
$$\text{P-Type: Si (4 val) + Trivalent (3 val: B, Ga, In) } \implies \text{Majority: Holes } (h^+)$$
$$\text{Mass Action Law: } n \cdot p = n_i^2$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Intrinsic vs Extrinsic Semiconductors:
- Intrinsic: Pure semiconductor crystal (Silicon, valence = 4) with no impurities. Low conductivity at room temperature.
- Extrinsic: Doped with tiny concentrations of impurity atoms to dramatically increase conductivity.

2. N-Type Semiconductor:
- Doped with Pentavalent impurities (valence 5: Phosphorus, Arsenic, Antimony).
- 4 valence electrons bond with Silicon; the 5th electron becomes a free conduction electron.
- Majority Carriers: Free Electrons ($e^-$); Minority Carriers: Holes ($h^+$).

3. P-Type Semiconductor:
- Doped with Trivalent impurities (valence 3: Boron, Gallium, Indium).
- 3 valence electrons bond with Silicon, leaving a vacancy or 'hole' ($h^+$).
- Majority Carriers: Holes ($h^+$); Minority Carriers: Electrons ($e^-$).

4. Mass Action Law:
$$n \cdot p = n_i^2$$

⚠️ EXAM PITFALL & CAUTION:

PN Junction Diode Biasing & Knee Voltages

📌 PROBLEM / QUESTION:
Explain Forward and Reverse Biasing of a PN junction diode. State the barrier potential (Knee Voltage) for Silicon and Germanium diodes, and explain the mechanism of reverse breakdown.
รูปประกอบ: PN Junction Diode Characteristic Curve & Biasing
📐 KEY FORMULAS & DEFINITIONS:
$$V_{\text{knee, Si}} \approx 0.7\text{ V} \qquad V_{\text{knee, Ge}} \approx 0.3\text{ V}$$
$$\text{Forward Bias: } V_{\text{anode}} > V_{\text{cathode}} + V_{\text{knee}} \implies I_D \text{ conducts heavily}$$
$$\text{Reverse Bias: } V_{\text{cathode}} > V_{\text{anode}} \implies I_D \approx I_s \text{ (Reverse Saturation Current } \approx \text{nA)}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Forward Bias (ไบแอสตรง):
Positive supply terminal connected to Anode (P-side), Negative to Cathode (N-side). When applied voltage overcomes the internal barrier potential ($0.7\text{ V}$ for Silicon, $0.3\text{ V}$ for Germanium), the depletion layer collapses and large forward current $I_D$ conducts exponentially.

2. Reverse Bias (ไบแอสกลับ):
Positive supply to Cathode (N-side), Negative to Anode (P-side). External voltage widens the depletion barrier, preventing majority carrier transit. Only an ultra-tiny temperature-dependent reverse saturation current $I_s$ (picoamps to nanoamps) leaks through.

3. Reverse Breakdown:
If reverse voltage exceeds Peak Inverse Voltage (PIV), avalanche multiplication causes sudden massive reverse current. Unless current is externally limited by a resistor, the diode burns out instantly.

⚠️ EXAM PITFALL & CAUTION:

Memorize: Silicon diode Knee Voltage = 0.7 V; Germanium diode Knee Voltage = 0.3 V. Standard problems assume Silicon 0.7 V.

$$I_D = I_s \left( e^{\frac{V_D}{n V_T}} - 1 \right) \qquad V_T = \frac{k T}{q} \approx 26\text{ mV at } 300\text{ K}$$
$$r_d = \frac{n V_T}{I_D} \approx \frac{26\text{ mV}}{I_D}$$

Zener Diode Voltage Regulator Operation

📌 PROBLEM / QUESTION:
How does a Zener diode function as a voltage regulator? In a circuit with Vin = 15 V to 20 V, Vz = 10 V, Pz_max = 1 W, and load RL = 500 ohms, calculate the required series resistor R.
รูปประกอบ: Zener Diode Voltage Regulator Circuit
📐 KEY FORMULAS & DEFINITIONS:
$$I_L = \frac{V_Z}{R_L} = \frac{10\text{ V}}{500\;\Omega} = 20\text{ mA}$$
$$I_{Z,\max} = \frac{P_{Z,\max}}{V_Z} = \frac{1\text{ W}}{10\text{ V}} = 100\text{ mA}$$
$$R_{\min} = \frac{V_{\text{in},\max} - V_Z}{I_{Z,\max} + I_L} = \frac{20 - 10}{0.100 + 0.020} = 83.3\;\Omega$$
$$R_{\max} = \frac{V_{\text{in},\min} - V_Z}{I_{Z,\min} + I_L} = \frac{15 - 10}{0.005 + 0.020} = 200\;\Omega$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Zener Regulation Mechanism:
A Zener diode operates in the REVERSE breakdown region. When reverse-biased beyond $V_Z$, terminal voltage remains clamped at $V_Z$ over a wide range of reverse current $I_Z$.

2. Load Current ($I_L$):
$$I_L = \frac{V_Z}{R_L} = \frac{10\text{ V}}{500\;\Omega} = 20\text{ mA} = 0.020\text{ A}$$

3. Maximum Zener Current ($I_{Z,\max}$):
$$I_{Z,\max} = \frac{P_{Z,\max}}{V_Z} = \frac{1\text{ W}}{10\text{ V}} = 100\text{ mA} = 0.100\text{ A}$$

4. Calculate Minimum Series Resistor ($R_{\min}$):
To protect the Zener from exceeding maximum power when $V_{\text{in}}$ is highest ($20\text{ V}$):
$$R_{\min} = \frac{V_{\text{in},\max} - V_Z}{I_{Z,\max} + I_L} = \frac{20\text{ V} - 10\text{ V}}{0.100\text{ A} + 0.020\text{ A}} = \frac{10\text{ V}}{0.120\text{ A}} = 83.3\;\Omega$$

5. Calculate Maximum Series Resistor ($R_{\max}$):
To maintain regulation at lowest $V_{\text{in}}$ ($15\text{ V}$) assuming $I_{Z,\min} = 5\text{ mA}$:
$$R_{\max} = \frac{V_{\text{in},\min} - V_Z}{I_{Z,\min} + I_L} = \frac{15\text{ V} - 10\text{ V}}{0.005\text{ A} + 0.020\text{ A}} = \frac{5\text{ V}}{0.025\text{ A}} = 200\;\Omega$$
Choose standard resistor $R = 120\;\Omega$ or $150\;\Omega$.

⚠️ EXAM PITFALL & CAUTION:

Zener diode must be connected in REVERSE BIAS (Cathode to positive supply) to regulate voltage. In forward bias, it behaves like an ordinary 0.7 V diode!

BJT Transistor Terminal Currents & Gain Relations

📌 PROBLEM / QUESTION:
State the current relationship between the Emitter (IE), Base (IB), and Collector (IC) of a Bipolar Junction Transistor (BJT). Define DC current gain Beta (hFE) and Alpha, and derive the formula linking Beta and Alpha.
รูปประกอบ: BJT Transistor Terminal Currents & Alpha-Beta Relations
📐 KEY FORMULAS & DEFINITIONS:
$$I_E = I_B + I_C$$
$$\beta = \frac{I_C}{I_B} \qquad \alpha = \frac{I_C}{I_E}$$
$$\alpha = \frac{\beta}{\beta + 1} \qquad \beta = \frac{\alpha}{1 - \alpha}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Kirchhoff's Current Law for BJT:
By KCL, total current passing through the emitter equals the sum of base and collector currents:
$$I_E = I_B + I_C$$

2. DC Current Gains Defined:
- Common-Emitter Gain ($\beta$ or $h_{FE}$):
$$\beta = \frac{I_C}{I_B} \quad (\text{typically } 50 - 300)$$
- Common-Base Gain ($\alpha$):
$$\alpha = \frac{I_C}{I_E} \quad (\text{slightly less than 1, typically } 0.98 - 0.998)$$

3. Mathematical Relationship Derivation:
Dividing $I_E = I_B + I_C$ by $I_C$:
$$\frac{I_E}{I_C} = \frac{I_B}{I_C} + 1$$
$$\frac{1}{\alpha} = \frac{1}{\beta} + 1 = \frac{\beta + 1}{\beta}$$
Inverting yields:
$$\alpha = \frac{\beta}{\beta + 1} \qquad \beta = \frac{\alpha}{1 - \alpha}$$

IE is always the LARGEST current in a BJT: IE = IB + IC. Collector current is slightly smaller than emitter current (Alpha < 1).

Operational Amplifier (Op-Amp 741) Characteristics

📌 PROBLEM / QUESTION:
State the ideal characteristics of an Operational Amplifier (Op-Amp): input impedance, output impedance, open-loop gain, bandwidth, and slew rate. Explain the concept of Virtual Short / Virtual Ground.
📐 KEY FORMULAS & DEFINITIONS:
$$R_{\text{in}} = \infty \implies I_+ = I_- = 0$$
$$R_{\text{out}} = 0 \qquad A_{OL} = \infty \qquad \text{Bandwidth} = \infty$$
$$\text{Virtual Short: } V_+ \approx V_- \quad (\text{Under negative feedback})$$
$$\text{Inverting Gain: } A_v = -\frac{R_f}{R_{\text{in}}} \qquad \text{Non-inverting Gain: } A_v = 1 + \frac{R_f}{R_1}$$
📝 STEP-BY-STEP MODEL SOLUTION:

1. Ideal Op-Amp Characteristics:
- Input Impedance ($R_{\text{in}}$): Infinite ($I_+ = I_- = 0$).
- Output Impedance ($R_{\text{out}}$): Zero (supplies load without drop).
- Open-Loop Gain ($A_{OL}$): Infinite ($10^5 - 10^6$ in real chips).
- Bandwidth ($BW$): Infinite (flat response from DC to $\infty$).
- Slew Rate: Infinite (instantaneous output slew).

2. Virtual Short & Virtual Ground:
Because open-loop gain $A_{OL}$ is infinite, in any closed-loop negative feedback configuration, the differential input voltage must be zero:
$$V_+ - V_- = \frac{V_{\text{out}}}{A_{OL}} = \frac{V_{\text{out}}}{\infty} = 0 \implies V_+ = V_-$$
This condition is known as a Virtual Short. If the non-inverting terminal $V_+$ is connected to physical ground ($0\text{ V}$), then $V_-$ is held at zero volts without being physically grounded, known as Virtual Ground.

⚠️ EXAM PITFALL & CAUTION:

Virtual short (V+ = V-) holds ONLY when negative feedback is present. In an open-loop comparator, V+ is NOT equal to V-.
